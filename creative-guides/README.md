# 무협스튜디오 창작 네 단계 지침

2026-10-09. 현행 workflow 3.1.0의 창작 기준을 작업자가 한 단계씩 읽을 수 있도록 기능별로 재정리했다. 운영·코드 전체 세트와 구판 기록은 이 묶음에 넣지 않는다. 최초 파일의 원래 바이트를 보존한 사본이나 새 창작 정책으로 해석하지 않는다.

[시놉시스·스크립트 개선 리스트](../references/CREATIVE_GUIDELINES_REVIEW_2026_10.md)는 별도의 검토 제안이다. 이 네 문서에는 아직 적용하지 않았다. 제안을 검토하기 전에 기존 규칙을 다시 바꾸거나 승인된 작품을 수정하지 않는다.

현행 문체·형식·설정 근거는 policy/01~07 및 관련 contracts/stages/workflow 문서다. 실제 최초 인수 지침과 이후 사용자 결정이 충돌하는 항목은 현재 기준을 따른다. 무조건 짧게 쓰기·어미 금지·대사 비율·예시 복제 등의 폐기 규칙은 다시 적용하지 않는다. 기존 완결 작품은 보존하고 다음 신작의 내부 16부→공개 4화·각 최종 영상 실측 1시간 이상 계획을 유지한다.

집필 시 모든 파일을 중복 주입하지 않는다. 이번 단계의 정리본과 관련 작품 정본·직전 원문을 읽고, 같은 내용의 원본 지침을 또 한 벌의 검사표로 겹쳐 적용하지 않는다. 적용 해석이 충돌하면 최신 사용자 지시와 현행 policy 원문으로 확인한다.

재정리의 근거는 커밋 f9ceb1094fe3474f4e5dfffbec71ea24f2f5f962의 관련 현행 문서다. 근거 문서나 사용자 규칙이 개정되면 영향받는 정리본도 함께 대조·갱신한다. 문서 준비, 실제 창작 검수, 실제 생성·음성·최종 영상 확인은 서로 다른 완료 수준이다.
