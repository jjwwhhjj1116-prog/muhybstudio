# 04. 장면 분할·시각화·Flow 파생 프롬프트 지침

이 문서는 무협스튜디오 현행 3.1.0의 장면 분할·시각화·연속 영상·파생 프롬프트 기준을 기능별로 재정리한 사용본이다. 새로운 분할 공식이나 모델 지원 보장이 아니다. 작품 원문과 사용자 예시 원문은 포함하지 않는다. 새 개선 제안은 아직 반영하지 않았다.

## 1. 입력과 작업 순서

확정 대본의 버전·원문·해시, 세계관·인물·무공 설정, 승인 캐릭터 디자인의 실제 이미지·해시, 현재 상태와 Flow 고정 등록명을 확인한다. 실제 TTS와 선택 시작·종료 이미지가 있으면 함께 확인하고, 없으면 시간·영상 지시는 초안으로 표시한다.

대본 확정 → 캐릭터시트와 등록 확인 → **장면 분할표 선저장** → 분할된 원문에 맞는 시각화 프롬프트 → 원문·의미·상태·화풍 검수 → Flow 이미지·영상 프롬프트로 진행한다. 영어 프롬프트부터 만들어 대본을 뒤에 끼워 맞추지 않는다. 기존 검수 장면표가 있으면 원문과 대조해 유지·수정 이유를 남기며 이유 없이 처음부터 다시 나누지 않는다.

## 2. 먼저 원문 소유권을 고정한다

나레이션과 직접 대사에 안정적인 문장 ID와 정확한 원문 위치를 부여한다. 화자·감정 태그·큰따옴표·글자·구두점을 보존한다. 각 원문 구간은 해당 시각화 장면에 중복 없이 배정한다.

공개 회차의 네 부를 통합한 원문 전체를 대상으로 한다. 내부 부·청크의 원문 ID와 공개 장면 번호는 별도 대응표로 연결한다. 공개 회차의 장면 번호는 1~N으로 이어지고 부가 바뀐다고 1부터 다시 시작하지 않는다.

긴 문장이 서로 다른 순간으로 이어지면 원문 위치를 보존한 의미·절 경계에서 나눌 수 있다. 문구와 대사를 다시 쓰거나 앞부분을 다음 장면에서 중복 낭독하지 않는다. 문장 목록 자체가 확정 원고 전체를 포함하는지도 확인한다.

## 3. 약 2~3문장·10초는 초기 묶음이다

같은 장소·시간·시점에서 이어지는 행동의 약 2~3문장을 한 장면으로 묶는 것을 출발값으로 삼는다. 짧은 호명과 반응은 함께 담을 수 있고, 전환·긴 대사·행동의 시작과 결과는 의미에 따라 조정한다.

이것은 고정 문장 수나 집필 문장 길이 조건이 아니다. 문장마다 자동으로 새 프롬프트를 만들지 않고, 장면 수를 줄이려고 서로 다른 장소·시간을 그림 한 장에 겹치지 않는다. 긴 대사를 억지로10초에 밀어 넣거나 장면 수에 맞춰 대본을 고치지 않는다.

현재 실행 모델 선택은 Veo 3.1 Lite이며 영상 초안은8초를 출발값으로 삼는다. **10초 묶음의 기획 기준과 Lite8초 실행 초안은 구분한다.** 실행 시 실제 모델·입력 모드·지원 길이를 UI에서 확인한다.10초 지원이나 특정 기능을 확인 없이 단정하지 않는다. 실제 TTS·쉼·동작에 따라 분할과 길이를 조정하고, 바뀐 분할은 세 납품 파일에 함께 반영한다.

## 4. 장면 분할표에 기록할 내용

| 항목 | 기록할 내용 |
|---|---|
| 식별과 범위 | 공개 회차, 장면 번호와 안정 ID, 내부 부, 원문 문장 ID·위치 |
| 원문 | 그 장면이 소유한 나레이션·직접 대사 전체 |
| 분할 이유 | 묶거나 나눈 사건·장소·시간·행동의 근거 |
| 사건·감정 | 관객이 알아야 할 변화와 그 순간의 감정 |
| 인물·상태 | 고정명, 의상·무기·소품·쥔 손·부상·젖음·구속·인지 상태 |
| 배경 | 중국 강호의 장소·시간·날씨·빛, 인물의 공간 배치 |
| 연기·구도 | 원문에 맞는 표정·행동의 이유, 카메라·시선·이동 축 |
| 동작의 흐름 | 시작 자세·진행 행동·종료 상태, 손과 물건의 역할 |
| 연결 | 다음 장면과 연속인지 CUT인지, 시작·종료 키프레임 ID와 실제 자산 연결 |
| 시간 확인 | 실제 음성 시각 또는 초안·예상 상태, 의도한 쉼과 액션 |

한 이미지에는 한 물리적 순간을 정한다. 시작과 종료의 전후 행동을 동시에 그리게 하지 않는다. 장면 분석·동작·키프레임 표는 전달용 시각화3줄 밖의 별도 자료다.

## 5. 납품 형식과 편집기 개행

시각화 한 장면은 다음 세 줄 형식이다. 아래는 형식 설명이며 작품 예문이 아니다.

```text
[장면 N]
[한국어 번역] 해당 장면의 대본 원문
[영어 이미지 프롬프트] 그 장면의 한 순간을 그리는 완결된 영어 프롬프트
```

`[한국어 번역]`은 새 번역·요약이 아니라 배정된 대본 원문이다. 나레이션과 감정 태그·큰따옴표 대사를 모두 보존한다. 이 원문은 **한 물리적 줄**로 쓴다. 원문의 문단·줄바꿈만 공백 하나로 연결하고 문구·구두점·태그·큰따옴표는 바꾸지 않는다. 원본 대본과 근거 자료에는 원래 문단을 보존한다.

세 줄 사이에 빈 줄이나 단독 대본 줄을 넣지 않는다. 특히 한국어 원문 도중과 한국어·영어 프롬프트 사이의 빈 줄은 넣지 않는다. 장면 사이에만 빈 줄 하나를 둔다. 화면의 자동 줄바꿈과 파일의 실제 개행은 다르다.

`[CTA]`는 Hook 마지막 장면 뒤, `[END]`는 End 첫 장면 앞에 원본 무음 표식으로 유지한다. 표식에 장면 번호를 부여하지 않는다. 공개 회차 전체에 한 번 적용하며 내부 부에서 반복하지 않는다.

## 6. 영어 이미지 프롬프트 작성

배정 원문의 사건과 감정, 등장인물의 실제 상태, 한 순간의 표정·행동·배경·구도를 영어로 명확하게 쓴다. 추상적인 고품질 문구만 늘리지 않는다. 인물이 왜 그 표정과 행동을 하는지 원문과 대조한다.

기존 한국 다크판타지 무협 액션 웹툰 화풍의 기본 문구는 다음 요소를 유지한다.

`Korean dark-fantasy martial-arts action manhwa webtoon style, hand-drawn illustration, ink line art with digital coloring, NOT photorealistic, NOT 3D render, NOT photograph, Masterpiece, ultra-detailed, premium anime key-visual quality, cel-shaded digital painting with ink brush texture, rich ink-wash rendering with dramatic lighting.`

승인 인물의 정확한 고정명과 같은 디자인·나이·얼굴·머리·복장을 사용한다. 실제 상태에 맞는 무기·소품·부상·흉터·젖음·구속과 좌우·쥔 손을 명시한다. 칼을 넣었다는 이유만으로 손이 비어 있다고 가정하지 않고, 부축·구조·열쇠 조작·물건 전달 등 실제 행동을 확인한다.

화면 가장자리까지 배경이 이어지는 단일 중국 강호 장면으로 쓴다. 시대에 맞는 복식·건물·무기를 구체적으로 설명한다. 조선시대 갓·삿갓·관복, 만화책 페이지 끝단·패널 테두리·분할 격자·자료판 이름과 칸을 장면에 옮기는 연출은 금지한다. 금지 대상을 길게 나열해 오히려 만화 페이지를 유도하기보다 원하는 단일 화면을 긍정문으로 설명한다.

불꽃·입자·바람·긴 공통 수식어는 모든 장면에 자동 추가하지 않는다. 화풍은 유지하되 해당 원문에 필요한 사건·감정·배경만 담는다. 같은 문구를 복사해 인물 상태와 행동이 서로 다른 장면을 대체하지 않는다.

## 7. 캐릭터명과 실제 참조

대본·설정·상세 시트·시각화·Flow 등록의 한글 고정명은 일치해야 한다. 이름을 적은 것, 프로젝트에 캐릭터를 등록한 것, 개별 생성 입력에 실제 참조를 첨부한 것은 별개의 확인이다.

장면 연기에 필요한 각도·상태의 단일 참조를 선택한다. 문자·격자 없는 한 인물·한 각도·한 상태의 이미지로 얼굴·머리·의상·부상을 대조한다. 모든 장면에 모든 참조를 첨부하지 않는다. 같은 얼굴로 이어져야 하는 조연도 실제 참조가 필요하며, 일반 군중은 외형·의상 앵커로 관리한다.

## 8. 시작·중간·종료와 연결

시작·종료 키프레임은 각각 그 순간의 상태이고 영상 프롬프트는 실제 이미지 사이의 행동이다. 연속 행동은 이전 종료 자산을 다음 시작 자산으로 공유한다. 동일 설명문을 복사해 서로 다른 그림을 연결점으로 쓰지 않는다. 구도·상대·시간·장소 전환이 필요하면 CUT으로 기록하고 시선·축·위치·행동을 이어 준다.

달리기·회전·검술은 사건과 감정에 필요한 흐름으로 설계한다. 모든 행동을 한 클립에 압축하거나 기계적으로 잘게 자르지 않는다. 검 뽑기·납검·구출·물건 전달은 물리적 순서와 손 역할을 명시한다. 대표 이미지가 이미 완료된 행동의 종료 자세라면 시작 입력과 대조해 같은 행동을 되풀이하라는 상충 지시를 고친다.

시작 이미지 한 장 방식에서는 종료 이미지를 무조건 요구하지 않는다. 시작+종료 모드를 쓸 때는 두 실제 입력을 확인한다. 얼굴이 바뀌는 문제를 정상 카메라 전환으로 처리하거나, 얼굴 숨기기·스틸 전환을 기본 해결책으로 삼지 않는다. 모델이 얼굴을 유지하거나 실패한다고 실제 시험 전에 단정하지 않는다.

## 9. Flow 이미지·영상 프롬프트와 수량

**시각화 N장면 = Flow 이미지 프롬프트 N개 = Flow 영상 프롬프트 N개.** 세 파일의1~N 번호와 순서는 동일 장면을 가리킨다. 내부 샷·키프레임·후보·재시도 이력과 납품 장면 수를 혼동하지 않는다.

시각화 밖 후속 컷이나 A/B/C 영상, 번호 없는 추가 작업으로 영상 프롬프트만 늘리지 않는다. 동작을 더 나눠야 하면 대본 원문을 새 시각화 장면에 중복 없이 재배정하고 세 자료의 수량·번호·내용을 함께 개정한다. 현재 납품 수량의 일치와 실제 최종 타이밍 검증은 구별한다.

검수한 영어 이미지 필드를 그대로 추출해 이미지 목록을 만든다. 영상은 장면의 시작 상태·중간 행동·종료 결과와 실제 선택 프레임에 맞춰 작성한다. 필요한 길이만큼 쓰며 고정 영어 단어 수를 강제하지 않는다. 공통 문구나 짧은 움직임 문장만으로 실제 행동 설계를 대체하지 않는다.

실제 시작·종료 이미지와 TTS 대조 전 영상 지시는 DRAFT다. 이미지 생성·선택 뒤 실제 그림을 보고 수정하고 선택 자산·음성 길이를 연결한다. 모델을 바꾸면 원문·장면 ID를 유지하고 길이·동작·입력 모드·음성 경로를 새 버전으로 대조한다. 정상 이미지를 무조건 다시 만들지 않으며 대사 삭제나 급한 낭독으로 길이를 맞추지 않는다.

## 10. 검수와 출력 묶음

먼저 원문 전체 포함·누락·중복·역순·발화 누락·태그·번호·수량을 검사한다. 이어서 장면 의미와 표정·행동·배경·화풍을 실제 원문과 읽어 대조한다. 기계적 수량·문자 검사는 인과와 연기의 자연스러움 판정을 대신하지 않는다.

상태 검수에서는 무기 인계·발도·납검·족쇄 해제, 칼의 주인·수량·쥔 손, 부상·젖은 옷·상처 방향, 소품 소유권, 시선·위치·이동 축이 앞뒤에서 되돌아가지 않는지 확인한다. 공개 회차 전체를 통합해 부 경계도 검수한다.

산출물은 장면 분할표, 시각화3줄 통합본, 동일번호 Flow 이미지·영상 프롬프트, 원문·인물 상태·키프레임·참조·영상의 대응표, 버전·해시와 수정·검수 기록이다. 텍스트 준비와 실제 생성의 확인 수준을 구분한다. 기존 수정본은 보존하고 새 버전을 사용한다.

실제 이미지에서는 캐릭터 동일성·표정·행동·배경·문화·테두리·워터마크를 확인한다. 실제 영상에서는 원본 얼굴과 시작·중간·끝 프레임 및 전환 순간을 대조하고 완성 클립을 재생한다. 양 끝이 맞아도 중간 얼굴·몸·무기·속도·방향과 접촉·피격 결과는 별도로 본다. 유사도 점수만으로 통과시키지 않는다.

선택 키프레임이 바뀌면 이를 사용하는 앞뒤 영상 작업도 다시 대조한다. 깨진 얼굴을 새 캐릭터 정본으로 누적 전파하지 않는다. 텍스트 추출, 파일·해시 존재, 캐릭터 등록, 실제 장면 참조 첨부, 생성·재생·시각 검수는 각각 다른 단계다. 문서가 준비됐다는 이유로 전체 영상 제작·타이밍·얼굴 보존을 완료했다고 하지 않는다.
