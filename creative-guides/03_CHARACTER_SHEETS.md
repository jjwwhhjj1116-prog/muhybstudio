# 03. 캐릭터시트 작성·이미지 제작·Flow 등록 지침

이 문서는 무협스튜디오 현행 3.1.0의 캐릭터·연속 영상 정책과 캐릭터 이미지 단계를 기능별로 재정리한 사용본이다. 원본 파일 사본이나 새 디자인 정책이 아니다. 기존 승인 웹툰 화풍·인물 디자인·상태를 유지한다. 새 개선 제안과 작품 원문·사용자 이미지 및 예시 원문은 수록하지 않는다.

## 1. 입력과 인물 식별

확정 대본, 세계관·등장인물·무공 설정집, 이번 공개 회차에 들어가는 네 부의 인물과 상태, 기존 승인 캐릭터 이미지, 화풍 참고 이미지와 실제 사용 상태를 확인한다. 이름과 설정의 근거가 되는 원문 버전을 연결한다.

주요 인물뿐 아니라 여러 샷에서 같은 얼굴로 이어져야 하는 조연·단역도 식별한다. ‘보조 인물 이미지 0’을 적용하지 않는다. 개별 정체성이 중요하지 않은 군중은 외형·의상 앵커로 관리한다. 인물 수를 무조건 세 명으로 제한해 사건을 바꾸지 않는다.

회상과 현재 인물, 이름 없는 아이와 후반의 주요 인물을 근거 없이 같은 인물로 합치지 않는다. 부가 바뀐다는 이유로 부상·복식·무기·감정을 초기화하지 않는다. 잠근 디자인은 재사용하고 실제 상태 변화가 있는 파생만 구분한다.

## 2. 캐릭터 텍스트 작성 양식

아래 항목은 현행 외형·설정·상태를 빠짐없이 전달하기 위한 작성 양식이다. 원문에 없는 눈·코·입·의상 등의 구체적 디자인 선택은 제작 제안으로 표시한다. 미정인 것을 기존 확정 사실처럼 쓰지 않는다. 설정을 늘리거나 정해진 신체 비율을 강제하는 새 규칙이 아니다.

| 구분 | 작성 필드 |
|---|---|
| 신원 | 정확한 한글 고정명, 별칭과의 대응, 소속·지위·서사 역할 |
| 나이·인상 | 현재 나이 또는 설정 범위, 회상 시 나이, 첫인상·위세·성격이 드러나는 특징 |
| 골격·체격 | 얼굴 골격과 윤곽, 체격·자세, 인물 간 구별점 |
| 눈 | 눈매·눈 색·시선의 인상, 상태 변화가 있는 눈과 좌우 구분 |
| 코·입 | 코의 형태·입매·입술의 인상, 수염이나 관련 외형 특징 |
| 머리 | 머리 색·길이·묶는 방식·장식, 정면·측면·후면에서 유지할 특징 |
| 옷 | 겉옷·속옷·바지·허리띠·신발, 색과 재질, 소속 특징, 젖음·손상·변장 |
| 무기 | 종류·형태·크기 인상·재질·칼집, 소유자와 사용하는 손, 발도·납검 상태 |
| 소품 | 장신구·패물·주머니·열쇠 등 식별 소품, 위치·소유권·쥔 손 |
| 지속 상태 | 부상·흉터·장애·구속·피로·젖음·의상 변화, 적용 장면과 근거 |
| 표정·동작 | 성격과 해당 사건에 맞는 표정·자세·행동, 상태에 따른 제한 |
| 참조 연결 | 승인 이미지의 역할, 상세 시트·단일 참조·파생 상태의 파일과 확인 정보 |

머리·복식·소품이 원화와 달라지지 않게 정면·측면·후면의 연결을 확인한다. 무기의 주인·수량·쥔 손과 부상 위치를 명확히 한다. 특정 장면의 감정은 기본 얼굴 구조와 구별하며, 감정 때문에 얼굴이 다른 인물로 바뀌지 않게 검수한다.

## 3. 유지할 화풍과 원화 참조

한국 다크판타지 무협 액션 웹툰 화풍을 유지한다. 기본 요소는 다음과 같다.

`Korean dark-fantasy martial-arts action manhwa webtoon style, hand-drawn illustration, ink line art with digital coloring.`

수작업 잉크 선화, 셀 셰이딩, 수묵 질감, 강한 명암 대비, 영화적 광원과 정교한 재질 표현을 살린다. 이를 일반 웹툰이나 부드러운 조명으로 임의 축약하지 않는다. 역사 참고 영상의 회화풍으로 바꾸거나 얼굴 문제의 원인이 화풍이라고 시험 전에 단정하지 않는다.

사용자가 승인한 실제 시트를 화풍·밀도·구성의 비교 기준으로 삼는다. 생성할 때 실제 승인 이미지를 참조로 넣고 화풍 참조와 인물 동일성 참조의 역할을 구분한다. 화풍 이름만 프롬프트에 쓴 것을 이미지 참조로 간주하지 않는다. 새 작품 인물에게 참고 작품의 얼굴·복장·부상을 무단 복사하지 않는다.

새 각도·표정·동작은 기존 디자인의 파생으로 만든다. 실제 결과를 원본과 비교해 먹선의 강약, 얼굴의 면과 명암, 머리카락·천·가죽의 재질, 색의 깊이, 나이·골격·체격·눈매·위세와 외형 매력을 확인한다. 해부·워터마크 검사만 통과했다고 화풍 검수를 완료하지 않는다.

## 4. 상세 캐릭터시트의 필수 구성

- 최상단에 정확한 한글 고정명을 크고 명확하게 표기한다. 영문명은 보조다.
- 같은 인물의 전신 정면·측면·후면, 표정 6종, 동작 5종을 구성한다.
- 의상·장신구·무기·핵심 소품의 확대와 색상 팔레트를 담는다.
- 중성 회색 또는 종이 질감 배경을 사용한다. 상세 자료판은 이름과 여러 칸을 사용할 수 있다.
- 사용자가 확정한 생성 요청은 모델 `gpt-image-2`, 품질 `medium`이다.
- 지정한 모델·품질을 실제 요청에 적용하고 기록한다. 설정할 수 없는 도구에서 적용했다고 주장하거나 다른 모델로 조용히 대체하지 않는다. 요청 설정과 실제 확인 수준을 구분한다.

텍스트만 작성하거나 얼굴 초상만 생성한 상태는 상세 시트 완료가 아니다. 주요 인물마다 실제 상세 시트와 생성 참조를 별도로 준비한다. 단일 참조만 있는 조연은 상세 시트가 없는 상태로 기록하고, 사용자가 상세 시트를 요청한 인물에게 단일 참조를 대신 납품하지 않는다.

## 5. 상세 시트와 단일 참조를 구분한다

| 자료 | 목적과 구성 |
|---|---|
| 상세 시트 | 제작진의 확인과 Flow 프로젝트 캐릭터 등록. 한글 이름·전신 3면·표정 6종·동작 5종·상세 소품을 담는 자료판 |
| 단일 참조 | 장면의 얼굴·자세·상태 제어. 한 파일에 한 인물·한 각도·한 상태, 문자·격자 없이 같은 디자인으로 제작 |
| 상태 파생 | 부상·의상·변장·회상 등 실제로 달라진 상태를 구별하고 적용 구간을 연결 |

단일 참조를 만들었다고 요청받은 상세 시트 업로드를 생략하지 않는다. 얼굴 연기가 필요한 샷은 얼굴이 충분히 보이는 참조를 선택하며 전신만 고집하지 않는다. 필요한 각도를 준비하되 모든 샷에 모든 참조를 첨부하지 않는다.

장면 이미지의 문자·격자 금지를 상세 자료판에 잘못 적용해 한글 이름과 필수 칸을 없애지 않는다. 반대로 상세 시트의 이름·칸·종이 배경을 장면 이미지에 옮기지 않는다.

## 6. Flow에 실제 캐릭터로 등록한다

캐릭터시트 단계는 실제 이미지 생성과 대상 Flow 프로젝트의 캐릭터 등록까지 포함한다. 고정명을 텍스트에 적거나 일반 미디어로만 업로드한 상태를 캐릭터 등록 완료로 보고하지 않는다.

다음 이름은 정확히 일치해야 한다.

**캐릭터 정본의 한글 고정명 = 상세 시트 최상단 이름 = 시각화 프롬프트의 캐릭터명 = Flow에 저장한 캐릭터명.**

1. 현재 지원되는 공식 브라우저 연결과 실제 대상 회차 프로젝트를 확인한다. 과거 프로젝트를 임의로 대상 삼지 않는다.
2. 기존 등록 인물·썸네일·디자인을 대조해 같은 자산을 중복 업로드하거나 다른 디자인을 덮어쓰지 않는다.
3. 실제 상세 시트를 업로드하고 정확한 한글 고정명을 입력해 저장한다. 별칭·영문명·파일명만으로 이름 저장을 대신하지 않는다.
4. 업로드 후 이름 없는 캐릭터가 이미 있으면 다시 업로드하지 않고 해당 항목에서 이름 저장을 이어간다.
5. 일반 미디어 카드와 구별되는 캐릭터 아이콘, 저장 이름과 썸네일을 확인한다. 새로고침 뒤에도 유지되는지 재확인한다.
6. 인물마다 원본 파일·해시, 대상 프로젝트, 확인 가능한 실제 캐릭터 ID, 이름 저장·아이콘·새로고침 결과, 마지막 완료 단계를 별도 기록한다. UI에서 얻지 못한 ID를 만들지 않는다.

상태는 `IMAGE_READY → UPLOADED → NAMED → REGISTRATION_VERIFIED`로 구별한다. 대상·로그인·연결이 불명확하면 준비 이미지는 보존하고 등록만 미완료로 남긴다. 특정 주소 확인 경로가 막혔다고 Flow 전체 불가나 사용자 설정 누락으로 단정하지 않는다. 현재 지원되는 연결 상태를 확인한 뒤 확인된 원인만 설명한다.

실제 UI가 상세 시트 입력을 받지 않으면 이유와 가능한 입력을 확인하고 미완료 상태를 기록한다. 등록 확인은 개별 장면의 참조 첨부와 별개다. 캐릭터명 문자열이 같다는 사실만으로 실제 이미지 참조가 연결됐다고 하지 않는다.

## 7. 캐릭터 단계 출력

- 인물별 텍스트 시트: 고정명, 외형·설정·현재 상태와 근거, 미정 또는 제작 제안의 구분.
- 실제 상세 시트와 같은 디자인의 단일 참조: 파일, 버전·해시, 각 참조 역할과 상태.
- 이름 대응표: 정본·시트·시각화·Flow 저장명, 대상 회차와 실제 등록 확인.
- 제작·등록 검수 기록: 구성·외형·화풍·상태·워터마크·캐릭터 아이콘·새로고침 유지와 미완료 항목.

이름을 바꾸면 시각화·Flow 파생 프롬프트·등록 대응도 함께 대조한다. 이미 허용된 제작을 단계마다 재승인받지 않고 이어간다. 실제 파일이 없으면 파일·해시를 비워 두며 생성이나 등록을 완료했다고 하지 않는다.

## 8. 최종 검수와 실패 후보

정확한 이름, 상세 구성, 인물 동일성, 설정 연속성, 화풍과 외형 매력, 의상·무기·소품·손 역할, 워터마크·로고·UI 흔적을 실제 이미지에서 확인한다. 중국 강호의 복식·무기를 따르고 조선시대 갓·삿갓·관복 같은 문화 혼입을 검수한다.

워터마크가 있는 결과를 무문자 참조로 통과시키지 않는다. 실패 후보는 보존하고 사유를 남기되 활성 등록부와 다음 장면 참조에서 제외한다. 수정본의 파일·해시를 파생 자료와 함께 갱신한다. 얼굴이 깨진 생성 결과를 새 인물 정본으로 채택하지 않는다.

캐릭터 등록 완료, 장면별 참조 첨부, 실제 이미지·영상 생성, 얼굴·동작의 재생 검수는 서로 다른 확인 수준이다. 텍스트와 파일 확인만으로 영상의 얼굴 보존이나 연속성을 보장하지 않는다. 새 개선 제안은 이 사용본에 반영하지 않았다.
