# 01. 시놉시스·등장인물·세계관 작성 지침

이 문서는 무협스튜디오 현행 3.2.0의 시놉시스·등장인물·세계관 지침을 창작 기능별로 정리한 사용본이다. 2026-10-09 사용자가 승인한 압축 10안 중 시놉시스 개선 1~6과 내부 부당 약 20분·공개화 목표 80분 편성을 반영했다. 별도 진단 문서의 12안 번호와 혼용하지 않는다. 다음 신작에 적용하며 기존 완료 작품과 승인 설정·대본·배분은 자동으로 바꾸지 않는다. 작품 원문과 사용자 예시 원문은 이 문서에 포함하지 않는다.

공통 시놉시스·세계관·인물 정본을 근거로 ‘무협소설(기존)’과 ‘무협웹툰(신규 실험)’ 두 제작 버전을 만든다. 핵심 선택·결과·관계·결말은 같고 전달 방식만 다르다. 버전별 낭독 원고와 해시·문장·장면 매핑을 따로 관리하며 실험을 이유로 기존 소설 원고를 덮어쓰지 않는다. 상세한 구분은 [두 버전 제작 정책](../policy/08_TWO_VERSION_PRODUCTION.md)을 따른다.

## 1. 목표와 입력

무협소설의 깊이, 인물의 위세와 격, 원한과 의리, 기연과 대결, 관계의 감정을 하나의 인과로 설계한다. 설정의 양이나 능력 상승 횟수를 재미의 기준으로 삼지 않는다. 설정집은 대본에서 모두 설명할 백과사전이 아니라 인물의 선택과 사건을 뒷받침하는 제작 기준이다.

작성 전에 다음 입력을 확인한다.

- 사용자가 준 소재, 선호하는 재미, 피하고 싶은 전개, 작품별 결정과 잠금.
- 기존 자료가 있으면 시놉시스·세계관·인물·무공 설정 원문과 확정된 사건. 요약은 원문을 찾는 색인으로 쓴다.
- 신작인지, 기존 작품의 재집필인지, 별도 몰아보기 편성인지. 신작 기본값을 기존 승인 자료에 자동 적용하지 않는다.
- 공개 회차와 내부 부의 배분, 이번에 작성할 범위, 결말에서 회수할 약속.
- 제작자가 제공한 문체 참고의 해설. 예시 속 사건·인물·능력을 새 작품의 설정으로 가져오지 않는다.

소재가 미정이면 후보를 제안할 수 있으나 사용자가 고르지 않은 후보를 확정 작품처럼 취급하지 않는다. 미확정 사실은 제안, 확정 자료와 대조된 사실은 수락 사실로 구별한다.

## 2. 시즌 기획을 먼저 잡는다

작품명보다 먼저 누가 무엇을 잃었고, 무엇을 되찾으려 하며, 왜 지금 움직여야 하는지를 정한다. 한 줄 기획에는 주인공의 처지, 당면 목표, 강한 방해자, 이 이야기만의 기연이나 갈등을 담는다. 어떤 응징·성장·관계·역전을 기다리게 할지 구체적으로 잡고, 훅이 만든 위세·위험·궁금증이 본편의 어느 행동과 결과에서 확인되거나 뒤집히는지 연결한다. 이름과 비급만 바꾸어 차별화를 대신하거나 훅의 대사 수·회상 구성을 공식으로 정하지 않는다.

시즌 기획에는 다음 내용을 연결해 쓴다.

| 항목 | 작성할 내용 |
|---|---|
| 중심 약속 | 시청자가 이 이야기를 계속 따라갈 이유와 기대할 감정 |
| 주인공 | 출발 처지, 당면 욕망, 두려움, 선택을 피할 수 없는 이유 |
| 상대의 계획 | 목적, 수단, 권력·무공·정보의 강점과 한계 |
| 전체 인과 | 앞의 선택이 뒤의 위기를 만드는 사건의 연결 |
| 기연과 성장 | 발견 과정, 얻는 조건, 사용 한계, 대가, 이전 난관을 바꾸는 효과 |
| 주요 관계 | 사제·동료·가문·문파·애정·적의가 충돌하고 달라지는 흐름 |
| 비밀과 공개 | 누가 무엇을 숨기는지, 단서와 공개 시점, 진실이 뒤집는 현재 목표 |
| 결말의 회수 | 중심 갈등과 약속의 결과, 관계의 변화, 주인공이 치른 대가 |

제작자용 기획에서는 결말을 숨기지 않는다. 중요한 전환점에서 주인공이 택한 길과 피하거나 포기한 길, 그 선택 때문에 생긴 다음 난관·기회·관계 변화를 확인한다. 앞 사건이 없어도 뒤가 그대로 진행된다면 연결의 근거를 고친다. 모든 장면에서 주인공이 주도하거나 희생해야 하는 것은 아니다.

상대가 주인공의 행동에서 무엇을 알아차렸고 어떤 수단을 유지하거나 바꾸었는지, 그 대응이 다음 선택을 어떻게 바꾸는지 연결한다. 알 수 없는 정보로 반격하거나 적의 판단력을 갑자기 없애 주인공을 돋보이게 하지 않는다. 승리 뒤마다 더 강한 새 적을 넣는 공식도 만들지 않는다. 역전은 앞서 준비한 능력·선택·관계·단서에서 나오게 한다.

## 3. 무협의 일곱 재미 관점

아래는 현행 시놉시스의 점검 관점이다. 모든 무협의 고정된 분류나 각 부에 일곱 가지를 전부 넣는 할당표가 아니다. 이번 작품에서 강하게 가져갈 재미를 중심 갈등에 묶는다.

| 관점 | 확인할 질문 |
|---|---|
| 위세와 격 | 명성·서열·압도적인 상대가 주인공에게 어떤 현실적 위험을 만드는가 |
| 원한과 역전 | 억울함·모욕·배신이 구체적 선택을 낳고 반격에 감정의 보상이 있는가 |
| 기연과 성장 | 발견·조건·대가가 있고 앞의 난관을 다르게 풀게 하는가 |
| 무공과 대결 | 승패가 수련·상성·판단·희생에서 나오며 결정적 초식이 사건을 바꾸는가 |
| 의리와 선택 | 사제·동료·가문·문파의 의리가 충돌해 쉬운 정답을 막는가 |
| 비밀과 반전 | 단서가 궁금증을 만들고 공개된 진실이 현재 목표나 관계를 뒤집는가 |
| 관계와 감정 | 애정·미련·질투·용서·상실이 인물다운 말과 행동에 남는가 |

기연·대결·반전을 따로 나열하거나 능력 상승 때마다 감정과 사건을 초기화하지 않는다. 수련과 기다림도 불안·기대·관계 변화가 쌓이는 구간이면 유지한다.

중심 기연·무공·복선·관계의 보상은 어떤 준비와 계기로 작동하고 난관을 푸는 방법이나 인물의 선택을 어떻게 바꾸는지 실제 사건으로 설계한다. 강한 무공을 얻는 일 자체보다 그것으로 누구를 살리고 어떤 원한을 뒤집는지가 방향을 만든다. 기술명 획득·진실 설명·화해 선언만으로 회수를 대신하지 않는다. 한 원리를 다르게 이해하고 적용하는 성장도 가능하며 매부 경지 상승이나 모든 소품의 회수를 요구하지 않는다.

중요한 의문에는 이번 구간에서 확인되는 부분, 남는 부분, 남겨야 할 사건상의 이유를 잡는다. 부분적인 답과 행동의 결과로 처지가 바뀌는지 확인하며 같은 질문을 변화 없이 미루지 않는다. 일정 시간마다 답이나 반전을 할당하지 않는다.

## 4. 세계관 설정집

중국 강호를 기본으로 삼고 아래 항목을 작품별로 명시한다. 익숙한 조직명을 사용해도 다른 작품의 구성 문파·기원·서열·권력 관계를 복사하지 않는다. 아래 필드는 현행 설정 요구를 정리하는 작성 양식이며 모든 작품에 새 제도나 사건을 추가하라는 뜻이 아니다.

| 구분 | 작성 필드 |
|---|---|
| 시대·문화 | 배경의 시대감, 복식·건축·생활의 기준, 작품에서 사용하는 명칭 |
| 지리·이동 | 주요 지역과 거점, 거리·이동 시간, 접근 조건, 사건 시점과 계절 |
| 구대문파 | 이번 작품의 구성, 각 문파의 성격·무공·지위, 문파 사이 관계 |
| 오대세가 | 이번 작품의 구성, 가문별 권력·무공·인물, 혼인·원한·협력 관계 |
| 무림맹 | 조직 기원, 정파와의 관계, 지휘·직위·권한, 결정을 집행하는 방식 |
| 사파 | 주요 세력과 목적, 정파·무림맹·천마신교와의 관계 |
| 천마신교 | 교의와 조직 기원, 교주·관련 직위의 권한, 외부 세력과의 관계 |
| 종교·관습 직위 | 신녀 등 해당 직책의 소속·권한·역할. 명칭과 실제 기능의 일치 |
| 갈등의 역사 | 현재 사건의 원인이 되는 과거 사건, 당사자, 알려진 기록과 숨겨진 진실 |
| 세계의 한계 | 무공·조직·정보·이동에 적용되는 조건과 예외의 근거 |

무협 배경에 맞지 않는 시대·문화·현대 제도 용어가 나오면 의미와 맥락을 확인해 고친다. 비슷해 보이는 단어로 무조건 치환하지 않는다. 조직명을 바꾸면 소속·직위·기원·사건의 인과까지 함께 검토한다.

세력·법도·무공 규칙은 누가 무엇을 허용하거나 막을 수 있는지를 통해 현재 사건에 적용한다. 명단과 경지를 본문에서 일괄 소개하지 않으며 현재 선택과 충돌하지 않는 정본 정보는 제작 자료에 남긴다.

## 5. 등장인물 설정집

한 인물의 고정명은 대본, 캐릭터시트, 시각화, Flow 등록에 일관되게 사용한다. 별칭은 고정명과의 관계를 기록한다. 외형의 실제 상세 설계는 캐릭터시트 단계에서 같은 고정명에 연결한다.

| 구분 | 작성 필드 |
|---|---|
| 신원 | 고정명·별칭, 소속, 지위와 역할 |
| 처지와 목적 | 현재 처지, 욕망과 당면 목표, 두려움, 움직이는 이유 |
| 숨긴 사실 | 누구에게 무엇을 숨기는지, 숨기는 이유와 공개 영향 |
| 지식 | 아는 사실, 오해·의심·모르는 사실, 그 정보를 얻은 사건과 시점 |
| 관계 | 상대별 신뢰·적의·욕망, 숨긴 일, 출발 관계, 아직 풀리지 않은 감정 |
| 무공 | 능력과 경지, 배운 경로, 사용 조건·한계·비용 |
| 지속 상태 | 위치·시간·생존·부상·피로·무기·소지품과 변화 근거 |
| 외형 연결 | 나이·인상·체격·머리·의상·무기 등의 근거와 캐릭터 자료 연결 |
| 서사 변화 | 어떤 선택으로 관계·정보·능력·대가가 바뀌는지, 이후 사건에 미치는 영향 |

작가만 아는 진실, 시청자에게 공개한 정보, 각 인물이 아는 정보를 분리한다. 인물의 믿음이나 거짓말을 세계의 사실로 확정하지 않는다. 미래 공개 정보를 현재 인물의 지식으로 넘기지 않는다. 근거가 없거나 모르는 값은 미정으로 남긴다.

주요 인물이 지키려는 사람·체면·원칙과 흔들리는 부분을 잡고 누구의 욕망과 충돌하는지 연결한다. 조연도 자기 목표 때문에 돕거나 거부하거나 판단을 바꿀 수 있다. 갈등을 만들기 위해 매번 숨은 배신자로 설정하지 않는다.

## 6. 무공 설정집

무공마다 이름, 사용자·전승, 경지와 수련 근거, 가능한 효과, 발동·사용 조건, 지속 한계, 비용과 후유증, 상성·대응 방법, 사건에서 드러날 시점을 정리한다. 앞선 난관을 바꾸는 능력이라면 발견 과정과 준비를 함께 기록한다.

승패는 수련·상성·판단·희생과 연결한다. 부상이나 영구적인 대가를 다음 부에서 이유 없이 초기화하지 않는다. 새로운 힘이나 예외가 필요하면 제안 사실로 남기고 앞의 설정·다음 사건·결말에 미치는 영향을 검토한 뒤 확정한다.

엔딩 방향은 사건 연결을 검토하는 기준이며 같은 반전 장치나 문장의 반복 공식이 아니다. 내부 부는 설계 단위, 공개 회차는 업로드 단위, 기술 청크는 작성·저장 작업 단위다. 청크 수는 필요한 작업량과 완결된 장면·대화 경계로 계획하며 고정 21개가 아니다. 미정 수량은 미정으로 남기고 착수 범위는 명시한다.

네 부를 한 편의 이야기로 연결한다. 부마다 Hook·Intro·요약·CTA·End를 다시 붙이지 않는다. 각 부의 결과가 다음 부의 원인이 되어야 하며 대사·부상·소지품·인지·감정이 이어진다. 부 안의 작은 해결과 절정은 가능하지만 같은 갈등을 네 번 종결하고 재시작하지 않는다. 부당 약 20분은 계획 기준이며 사건의 비중에 따라 예상 분량은 조정할 수 있다.

## 8. 시놉시스 출력 묶음

다음 다섯 자료를 서로 연결해 제공한다. 빈 양식을 만들었다고 기획 완성으로 보고하지 않는다.

1. 시즌 기획: 중심 약속, 양측 목표, 전체 인과, 주요 관계, 기연의 조건·대가, 결말 회수.
2. 세계관·등장인물·무공 설정집: 위 항목을 각각 구분하고 확정·제안 사실과 정보 공개 시점을 표시.
3. 공개 4화 계획: 중심 질문, 시작 상태, 행동과 예상 밖의 결과, 결정적 선택, 국소적 해결, 남는 감정, 엔딩, 다음 회차의 원인, 목표 80분과 예상·실측 확인 상태.
4. 내부 16부 상세 시놉시스: 시작 상태, 욕망과 방해, 주요 사건, 선택과 정보 기반 대응, 결과, 달라진 관계·정보, 기연·복선·회수, 다음 부로 이어지는 원인, 부당 약 20분 계획.
5. 배분표와 검토 기록: 내부 P01~P16을 공개 EP01~EP04에 각각 한 번 배정하고 원문 범위·버전·검토 근거를 연결.

배경 소개를 반복하는 대신 실제 사건을 쓴다. 이미 결정한 중심 질문을 같은 적·비밀의 유보와 설명으로만 늘리지 않는다. 시놉시스에는 시간 목표, 대본에는 예상 길이, 완성 영상에는 실측 길이를 따로 기록한다.

## 9. 인과·기억·복선 검수

전체 공개 회차를 이어 읽으며 앞의 선택이 뒤의 위기를 만드는지, 역전·반전·결말이 앞에서 준비됐는지, 능력과 대가가 서로 충돌하지 않는지 확인한다. 인물의 욕망과 감정이 이유 없이 바뀌지 않는지, 적이 자기 목적과 정보의 한계 안에서 판단하는지 읽는다.

세계·인물 정본, 현재 상태, 인물별 지식, 상대별 관계, 미해결 복선·약속, 사건 순서와 서술 순서, 오류·수정 기록, 마지막 확정 지점은 구분해 관리한다. 사실에는 근거 원문·버전·문장 위치와 적용 시점을 연결한다. 계획은 planned, 검수 전 추출은 proposed, 확정 원문과 대조한 사실만 accepted로 구별하며 근거가 삭제·변경된 기억은 stale로 표시한다. 감정 해석처럼 단정하기 어려운 것은 관찰·가설로 남긴다.

집필할 때 해당 인물·장소·소품의 근거와 직전 완결 장면을 읽는다. 대화는 공방의 필요한 범위를 읽고 마지막 두 문장만으로 연결을 판단하지 않는다. 과거 단서·무공·사건이 다시 나오면 원문을 확인한다. 새 초안의 잘못된 상태로 기존 정본을 덮어써 정당화하지 않는다.

배분 검수에서는 16부의 중복·누락·역순, 공개 회차 귀속, 최종 4화의 일치, 부와 회차 연결을 확인한다. 재미 평가에는 실제 약점과 수정 근거를 남긴다. 숫자 점수만 올려 기획이 개선됐다고 하지 않는다.

## 10. 부당 20분·공개화 80분 목표의 확인

두 버전 모두 신작 내부 16부·부당 약 20분, 공개 4화·화당 목표 80분(4,800초), 버전별 전체 목표 320분으로 계획한다. 이전 신작 최소 길이 기준은 이 목표로 대체한다. 현재 성우의 실제 샘플로 예상 낭독 범위를 계획하며 음성이 없으면 예상이라고 표시한다. 실측 전 값은 미정이다. 네 부×20분 계산이나 글자 수만으로 실제 80분 완성을 표시하지 않는다.

발화와 동시에 진행되는 영상은 한 번만 센다. 의도한 무음 액션·감정의 기다림은 최종 편집에 실제 있는 길이만 포함한다. 짧은 이야기를 반복 요약·침묵·불필요한 느린 낭독으로 늘리지 않는다. 목표에 못 미치면 빠진 선택·관계·난관·회수를 검토해 필요한 서사를 새 개정본에 보강한다. 시간 계획 검증은 실제 음성·영상·시각 검수의 완료를 뜻하지 않는다.

후속 시각화는 각 버전의 신작 공개화당 200장면 이내다. 무협소설은 시각화 N=이미지 N=영상 N, 무협웹툰 실험은 시각화 N=기본 이미지 N=모션 구간 N에 선택 Flow 영상 K개를 원래 장면 ID로 연결한다. 약 2~3문장은 초기 의미 묶음이고 8초 생성 클립과 20~30초 안팎의 편집 구간은 별개다. 상한이나 생성 길이를 맞추려고 낭독 원문을 삭제·축약하지 않으며 자세한 분할·편집은 해당 영상 단계에서 실제 자료로 검수한다.
