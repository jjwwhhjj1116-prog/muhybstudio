# 02B. 무협 웹툰판 대본 집필 사용본

2026-10-10 / WEBTOON_EXPERIMENT 전용. 현행 기준 전문은 [무협 웹툰판 대본 작성 지침](../policy/09_WEBTOON_WRITING.md)이다. 이 문서는 집필 진입과 자료 전달을 위한 사용본이며 또 한 벌의 추가 규칙이 아니다. 기존 소설판은 [02 스크립트 작성 지침](02_SCRIPT_WRITING.md)을 유지한다.

## 이번 버전의 핵심

**인물의 대화·선택·반응으로 진행하고 나레이션은 필요한 맥락·격·감정을 잇는다.** 웹툰판은 소설 설명을 대사로 변환하는 작업이 아니다. 무협의 위세·격정·기연·대결·의리를 살리되 말풍선을 채우기 위한 문답, 모든 인물이 같은 명언을 하는 발화, 이미 보인 행동의 나레이션 중계는 고친다.

대사 비율·문장 길이·어미 횟수는 강제하지 않는다. 상대를 설득하고 밀어내고 보호하려는 말, 체면 때문에 삼키는 말, 승패 뒤에 남는 감정으로 인물을 만든다. 모든 한마디가 절정일 필요는 없다. 화면만으로 어려운 원인·능력 조건·내면은 짧은 나레이션으로 전달할 수 있다.

## 집필에 제공할 최소 자료

1. 공통 시놉시스와 이번 공개 회차의 네 내부 부 배분.
2. 관련 인물·세계관·무공의 원문, 현재 인지·부상·무기·감정, 사용자 잠금.
3. 직전 웹툰판의 필요한 완결 장면·공방. 첫 화는 시작 상태.
4. 선호하는 사용자 원문이 있으면 지정 구간과 해설. 문장·사건을 복제하지 않는다.
5. 제작 버전 WEBTOON_EXPERIMENT와 이번 작업 범위. 운영 문서 전체를 작가에게 반복 주입하지 않는다.

소설판을 먼저 완성하지 않아도 공통 시놉시스에서 직접 쓸 수 있다. 두 판의 주요 선택·결과·관계·결말은 공유하고 표현·원고·해시는 분리한다.

## 대본과 제작 메모의 분리

| 결과물 | 담을 내용 |
|---|---|
| 낭독 대본 | 모든 실제 나레이션과 `[화자명|감정]"대사"`. 일반 서술은 성우가 읽는다. |
| 전달 메모 | 화면에만 맡길 사실·무음 반응, 공통 사건 근거·연결 발화·필요 그림·전달 의도. 비낭독 자료다. |
| 개선·검수 기록 | 실제 문제 위치·수정 이유·공통 정본 대조·전후 판단·미확인 사항. 비낭독 자료다. |

빈 [작업 서식](../templates/webtoon_script_notes.template.md)은 전달 메모용이다. 대본에 카메라·음향·말풍선·모션 지문을 끼워 넣지 않는다. 중요 사건을 대본에서 빼고 메모에도 남기지 않는 누락을 검사한다. 화면 전달을 계획했다는 사실은 실제 그림의 검수 완료가 아니다.

감정은 내추럴·화남·슬픔·기쁨·행복·놀람·FIRM을 쓰며 FIRM의 기존 제한을 유지한다. 실제 속마음은 나레이션으로 표현하고 상대에게 말한 대사처럼 꾸미지 않는다. 큰따옴표는 직접 대사에 쓴다.

## 편성과 장면 수

내부 16부×약20분 → 네 부씩 공개 4화×목표80분, 최종 실측4,800초 이상이다. 공개화마다 Hook·Intro·Body·Climax·End 한 벌과 무음 `[CTA]`·`[END]`를 사용한다. 내부 부·기술 청크에서 반복하지 않는다. 공개 마지막 발화는 직접 대사이며 최종 공개화는 이야기의 회수와 인물다운 마지막 말로 마무리한다.

대본 확정 뒤 의미 장면 N≤200을 분할한다. 약2~3문장은 출발값이며 한 대사·한 말풍선이 한 장면이라는 뜻이 아니다. 웹툰판은 N=기본 원화 N=모션 계획 N, 선택 Flow K≤N이다. 장면 안 편집 컷·말풍선·보조 그림은 별도 집계하고 새로운 사건을 숨겨 수량을 줄이지 않는다. 기본 원화 확대만으로 새 표정·자세·검술을 구현했다고 가정하지 않는다.

## 작업 순서와 점검

공통 사건과 인물 상태 읽기 → 현장 대화·행동과 필요한 나레이션으로 초안 → 설정·형식 검수 → 자연스러운 공방·감정·중복 설명·호흡 개선 → 네 부 전체 연결 검수 → 버전·해시 확정 → 캐릭터시트 → 장면 분할·시각화다. 이미 일괄 진행을 요청받았으면 중간 재승인을 요구하지 않는다.

반복 설명·갑작스러운 결론·번역투·같은 박자의 종결·설명만 하는 대사를 실제 구절에서 수정한다. ‘다’를 금지하거나 어미만 돌려 쓰지 않는다. 대사의 의미와 순서는 나중에 말풍선을 나누어도 보존한다. 텍스트 예상·편집 점수·실제 청취·실제 화면 검수는 구분한다.

복사할 최소 집필 지시는 [전용 지침 마지막 항목](../policy/09_WEBTOON_WRITING.md#10-작업자에게-전달할-최소-집필-지시)에 있다. 제작 도구는 후속 단계에서 선택하며 이 집필 사용본을 만들었다고 이미지·TTS·Remotion 영상이 완성된 것은 아니다.
