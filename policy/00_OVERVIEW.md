# 무협스튜디오 V13 제작 기준

무협소설의 깊이를 가진 연속 무협 애니메이션을 제작한다. 작가는 사건과 대사를 직접 집필하고, 기존 웹툰 디자인을 유지하며 Google Flow의 Omni 1.1 Flash에 맞춰 시작·종료 프레임과 행동을 연결한다. 정적인 오디오북으로 제작 목표를 낮추지 않는다.

네 가지 개선 범위는 집필 자유와 발화, 서사·기억·검수, 연속 애니메이션 장면 분석, Flow 생성부터 최종 출력까지의 자동화다.

최신 사용자 지시가 우선한다. 실행 기준은 policy/의 V13이며 기존 경로의 문서는 이 기준으로 안내한다. 과거 V12 전문은 Git 이력으로만 조회한다. 작품 사실은 별도 비공개 프로젝트의 원문에서 읽는다. 작가에게는 [집필 지침](01_WRITING.md), 필요한 사실과 직전 장면만 제공한다. 운영 문서·검수 사례·상시 예문을 매 집필 입력에 넣지 않는다.

공개 16회×약15분과 상위21개 기술 청크가 현재 기본값이다. 하위 분할과 장면 수는 사건 및 실제 음성 길이에 맞춘다. 21청크는 회차 수가 아니다. 기존 대본의 전면 재집필을 허용하되 새 작품 사실의 proposed/accepted 상태를 구분한다.

이 저장소에는 범용 지침·스키마·초기화·동기화 점검·검증 도구를 둔다. Flow 생성 확장 프로그램, TTS 어댑터, 실제 얼굴/영상 검수와 렌더 자동화의 구현 여부는 [상태 기록](../coordination/STATUS.md)에서 확인한다. 명세를 실행 완료로 표시하지 않는다.

세 PC의 공유 기준은 main이다. [동기화 절차](../workflow/12_THREE_PC_SYNC.md)를 따른다. 미공개 작품 자료는 공개 Git에 올리지 않으며 로컬에만 있는 작품 자료가 Git pull로 전송된다고 설명하지 않는다.
