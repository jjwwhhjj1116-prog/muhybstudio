# 무협스튜디오 제작 기준 — 소설형 나레이션과 포인트 대사

무협소설의 깊이를 가진 연속 무협 애니메이션을 제작한다. 작가는 사건과 대사를 직접 집필하고, 기존 웹툰 디자인을 유지하며 Google Flow / Veo 3.1 - Lite의 현재 입력 모드와 실제 프레임을 확인해 행동을 연결한다. 정적인 오디오북으로 제작 목표를 낮추지 않는다.

2026-09-07 사용자 대표 원고와 후속 지시에 따라 현행 집필 지침을 개정했다. 서사 기억, 연속 영상, Flow 자동화와 Git 공유는 별도 제작 영역이다.

최신 사용자 지시가 우선한다. 대본 작성·출력·검수는 [현행 집필 지침](01_WRITING.md)과 출력·검수 계약을 따른다. 대본을 비낭독 지문과 대사 중심 각본으로 바꾸지 않는다. 작품 사실은 비공개 프로젝트에서 읽는다.

다음 신작의 기본값은 내부 16부를 네 부씩 묶은 공개 4화이며, 각 최종 영상은 실측 3,600초 이상이다. [시놉시스·편성 지침](07_SYNOPSIS_AND_RELEASE_PLAN.md)에 따라 공개 회차별 이야기의 진행과 회수를 먼저 설계한다. 기술 청크 수는 작업 계획에서 정하고 부·회차 수와 혼용하지 않는다. 문장 수·고정 속도·반복 설명으로 한 시간을 채우지 않는다.

이 개정은 새 이야기의 기획부터 적용한다. 기존 완료 작품과 승인 원고·자산·Docs·회차 배분은 그대로 보존한다. 다른 편성으로 다시 만드는 요청이 있으면 별도 개정본과 대응표로 처리한다. 초안 및 새 작품 사실의 proposed/accepted 상태도 계속 구분한다.

이 저장소에는 범용 지침·스키마·초기화·동기화 점검·검증 도구를 둔다. Flow 생성 확장 프로그램, TTS 어댑터, 실제 얼굴/영상 검수와 렌더 자동화의 구현 여부는 [상태 기록](../coordination/STATUS.md)에서 확인한다. 명세를 실행 완료로 표시하지 않는다.

세 PC의 공유 기준은 main이다. [동기화 절차](../workflow/12_THREE_PC_SYNC.md)를 따른다. 미공개 작품 자료는 공개 Git에 올리지 않으며 로컬에만 있는 작품 자료가 Git pull로 전송된다고 설명하지 않는다.
