# 같은 이야기의 소설판과 웹툰판

2026-10-09 사용자 결정: 기존 방식을 교체하지 않는다. 다음 신작을 무협 소설 버전 `NOVEL`과 신규 시도인 무협 웹툰 버전 `WEBTOON_EXPERIMENT`으로 구성한다. 기존 완료 작품과 승인 원고·미디어는 이 실험 때문에 수정하지 않는다.

## 공통 이야기와 공개 편성

시놉시스·세계관·인물·무공의 조건, 중요한 선택과 결과·관계·결말은 하나의 공통 작품 정본에서 관리한다. 내부 16부는 각각 약 20분을 계획하고 네 부씩 공개 1~4화에 배정한다. 각 공개 버전의 목표는 80분, 최종 확인 기준은 4,800초 이상이다. 소설판 네 편과 웹툰판 네 편은 표현을 비교하는 두 묶음이며, 여덟 개의 서로 다른 이야기 회차가 아니다. 글자 수와 침묵으로 시간을 채우지 않는다.

표현을 바꾸다 중요한 행동·인지·관계·결말을 바꿀 필요가 생기면 공통 설정의 proposed 변경과 영향을 먼저 기록한다. 한 버전에만 새 기연이나 사건을 몰래 넣지 않는다. 원작처럼 보이게 하려고 참고 작품의 고유 인물·조직·기연·장면·대사를 옮기지 않는다.

## 두 대본의 전달 방식

실제 집필 진입은 NOVEL → [소설판 지침](01_WRITING.md), WEBTOON_EXPERIMENT → [웹툰판 전용 지침](09_WEBTOON_WRITING.md)이다. 웹툰판은 공통 시놉시스에서 직접 쓸 수 있으며 소설판 선완성을 필수 조건으로 만들지 않는다. 소설형 나레이션 비중을 두 판에 중복 강제하지 않는다. 웹툰판의 화면 전용 사실·무음 반응은 별도 전달 메모에 근거와 연결 위치를 남긴 뒤 확정 후 장면표에 이관한다.

| 항목 | NOVEL — 기존 소설 버전 | WEBTOON_EXPERIMENT — 신규 웹툰 버전 |
|---|---|---|
| 이야기 전달 | 감정이 있는 소설형 나레이션과 포인트 대사 | 인물이 현장에서 부딪치고 선택하는 대화·표정·반응, 필요한 나레이션 |
| 나레이션 | 위세·상황·내면·사건을 귀로 따라가게 전달 | 공간·시간 전환, 시야 밖 사건, 무공의 격과 말만으로 전달하기 어려운 내면을 보완 |
| 대사 | 상황과 기대를 바꾸는 공방에 집중 | 말풍선과 성우 발화로 보여 주되 작가의 설명을 등장인물 입에 그대로 넣지 않음 |
| 화면 | 장면 이미지와 해당 장면의 생성 영상 | 장면 이미지·표정/소품 컷·말풍선·재구도·모션, 선택한 훅과 핵심 장면만 생성 영상 |
| 낭독 원고 | 모든 일반 서술은 나레이션, 감정 태그 직접 대사 | 모든 낭독 내용과 감정 태그 직접 대사를 포함하고 편집 지시는 별도 |

두 버전 모두 직접 대사는 `[화자명|감정]"대사"`이고 현행 감정 목록과 FIRM 범위를 유지한다. 공개 회차의 마지막 발화는 직접 대사다. 웹툰판을 대사 비율·대사 수 증가 목표나 비낭독 지문을 섞은 영화 각본으로 바꾸지 않는다. 화면으로 대신할 정보는 웹툰판 원고에서 의도적으로 검토하고 대응 장면에 기록하며 소설판 정본을 삭제하지 않는다.

## 200장면과 생성 영상 수

공개 회차마다 두 버전을 따로 분할한다. 각각 `1 ≤ N ≤ 200`이다. 같은 장소·시간·행동의 2~3문장을 초기 묶음으로 삼고 문장마다 자동 분할하지 않는다. 두 원고의 분량과 정보 전달이 다르므로 두 버전의 N이 반드시 같을 필요는 없다. 중요한 사건·공통 내부 부 ID로 대응한다.

- **NOVEL:** 시각화 N = 기본 이미지 프롬프트 N = Flow 영상 프롬프트 N. 기존 1:1 계약을 유지한다.
- **WEBTOON_EXPERIMENT:** 시각화 N = 기본 이미지 프롬프트 N = 편집 모션 계획 N. 생성 영상은 선택한 장면의 K개, `0 ≤ K ≤ N`으로 별도 기록한다. 훅과 핵심 장면을 우선 검토하며 나머지를 가짜 Flow 프롬프트로 채우지 않는다. K 목록에는 원래 장면 ID와 원고 버전이 있어야 한다. 별도 1~K로 다시 번호를 매겨 원문 대응을 끊지 않는다.

웹툰판에서 한 장면의 전체 컷·표정 확대·손·상대 반응 등 편집 컷, 발화별 말풍선과 텍스트 등장은 N과 별개다. 같은 실제 그림의 재구도나 승인 표정 참조를 사용할 수 있으나 새로운 표정·행동·배경이 필요한데 확대만으로 구현했다고 표시하지 않는다. 새 반응 그림은 보조 자산 목록에 실제 파일·생성/재사용 구분·검수를 남긴다. 장면 수를 줄였다는 이유로 실제 필요한 보조 이미지 생성비까지 0이라고 계산하지 않는다. 인물·무기·부상의 좌우를 바꾸는 무분별한 좌우 반전은 피한다.

시각화 편집기 입력은 두 버전 모두 기존 3줄 규격이며 한국어 원문 내부 빈 줄이 없다. 모션·말풍선·음성 시각은 별도 편집표에 둔다. [장면과 파생 프롬프트 계약](../contracts/03_DERIVED_PROMPT_CONTRACT.md)의 버전별 대응을 따른다.

## 웹툰 영상의 화면과 음성

기존 한국 다크판타지 무협 웹툰 화풍과 이름 있는 캐릭터시트를 유지한다. 장면 원화는 깨끗한 16:9 화면으로 만들고 한국어 말풍선·타이포·선택한 패널 구획은 후편집한다. 모델이 임의로 그린 만화책 테두리·페이지 끝·깨진 글자를 그대로 사용하지 않는다. 의도한 패널 구획은 인물 얼굴과 중요한 손·소품을 가리지 않게 설계한다.

말풍선의 내용·화자·등장/제거 시각은 해당 버전의 실제 발화와 대응한다. 긴 대사를 발화 의미 단위로 나눌 수 있지만 말을 누락하거나 순서를 바꾸지 않는다. 태그·화자 관리 표식은 화면에 나오지 않는다. 같은 대사를 말풍선과 별도 하단 자막으로 중복 표시하지 않으며 접근성 자막이 필요하면 표시 방식을 따로 검토한다. 타이포는 결정적 한마디·초식·충격에 선택해 적용하고 모든 단어를 흔들거나 확대하지 않는다.

모션은 의미가 있는 시선 이동·재구도·반응 컷 전환·짧은 충격·집중을 중심으로 계획한다. 모든 컷에 같은 확대를 반복하지 않는다. 정지 그림에 말풍선이 있다고 입모양 연기가 구현됐다고 하지 않는다. 배역별 고정 성우와 연기는 실제 샘플로 선택하고, 두 원고의 대사가 달라졌으면 음성을 각 원고에 맞춰 생성한다. 원문·보이스·연기 조건이 정확히 같은 발화만 해시로 재사용한다.

## 시간과 검증

80분/200장면이면 평균 표시 시간은 24초다. 이것은 최종 편집 구간의 평균이며 Flow 클립 길이가 아니다. Lite 8초 클립 200개는 총 1,600초이고 80분 전체의 연속 움직임을 충족하지 않는다. 소설판도 이미지 재구도·실제 클립·표정의 기다림을 어떻게 조합할지 따로 계획한다. 웹툰판은 발화별 말풍선과 화면 반응으로 표시 구간을 전개한다. 무의미한 정지·클립 무한 반복·일괄 3배 감속으로 시간 부족을 숨기지 않는다.

첫 비교는 같은 사건 범위의 3~5분 소설판/웹툰판 파일럿으로 계획할 수 있다. 이미 허용된 제작을 청크마다 다시 승인받는 관문은 아니다. 파일럿의 실제 대사·나레이션 이해도·표정·읽는 속도·음성·모션을 확인하고 발견한 문제를 본편 설계에 반영한다. 문서 초안·테스트 통과·자체 점수가 시청 유지율이나 흥행의 검증을 대신하지 않는다.

## 저장과 섞임 방지

비공개 작품 아래 공통 `canon/`·`synopsis/`·승인 캐릭터 자료를 두고 `versions/NOVEL/`, `versions/WEBTOON_EXPERIMENT/`에 각 대본·원문 해시·장면표·프롬프트·음성·편집표·제목/설명/썸네일·검수 상태를 분리한다. Docs도 대상 버전과 탭을 확인한다. 파일명·색인·매니페스트에는 공개 회차와 `production_version`을 포함한다. 아직 선택되지 않은 문구와 장면은 proposed다.

초기화 도구의 기본값은 NOVEL이며 WEBTOON_EXPERIMENT는 명시적으로 선택한다. 한 폴더의 manifest를 바꿔 기존 산출물을 다른 버전으로 둔갑시키지 않는다. 현재 구조 검증기는 선언된 배분·목표·수량·버전의 일치를 검사할 뿐 실제 프롬프트 의미·말풍선·음성·렌더를 검수하지 않는다. 두 버전을 완성하려면 실제 자료별 검수가 남는다.
