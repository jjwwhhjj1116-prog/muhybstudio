# 캐릭터와 연속 영상의 장면 분석

대본 → 캐릭터시트 → 장면 분석·시각화 → Flow 파생 프롬프트의 현행 절차는 workflow/13_SCRIPT_TO_PROMPTS.md를 따른다. 조선시대 갓·삿갓·관복과 만화책 페이지 테두리·분할 격자는 이 채널의 강호 시각화에서 금지한다. 문파별 외형과 복식은 작품 정본과 캐릭터시트에 맞추며 실제 이미지에서도 검사한다.

## 화풍과 캐릭터

기존 웹툰 이미지의 화풍·인물 디자인을 유지한다. 역사 참고 영상의 회화풍으로 바꾸거나 얼굴 문제를 화풍 탓으로 단정하지 않는다. 기존 원본을 받은 뒤 특징과 실제 사용 상태를 등록한다. 새 각도·표정·동작 이미지는 기존 디자인에 맞춰 만들며 재디자인으로 대체하지 않는다.

인물 설정 자료판은 제작진 확인용, 생성 참조는 모델에 실제 첨부할 이미지로 분리한다. 생성 참조는 한 파일에 한 인물·한 각도·한 상태로 정리하고 문자·격자를 넣지 않는다. 전신만 고집하지 않고 얼굴 연기가 필요한 샷에는 얼굴이 충분히 보이는 참조를 선택한다. 각도별 참조를 만들되 모든 샷에 모든 이미지를 첨부하지 않는다. 부상·의상·변장의 지속 상태는 별도 state_id로 추적한다.

조연도 여러 샷에서 같은 얼굴로 이어져야 하면 실제 참조를 만든다. '보조 인물 이미지 0'은 폐기한다. 군중 등 개별 정체성이 중요하지 않은 경우 외형·의상 앵커를 쓴다. 인물 수를 무조건 3명으로 제한해 사건을 바꾸지 않으며, 다인 장면은 시선과 공간 관계를 알아볼 수 있게 연출한다.

등록명 문자열만 썼다고 이미지 참조가 연결된 것으로 보지 않는다. 현재 Flow의 실제 자산 첨부/참조 방식과 입력 상태를 확인한다. 긴 공통 수식어·불꽃·입자·바람을 모든 장면에 자동 추가하지 않는다. 기준 화풍과 해당 장면에서 필요한 정보만 사용한다. 시트·격자 구도를 유도하는 문구는 생성 프롬프트에 넣지 않는다.

## 원고에서 샷으로

대본 확정 뒤 장면 분할을 먼저 하고, 분할한 대본 장면에 맞춰 시각화 프롬프트를 만든다. 문장에는 안정적인 sentence_id를 부여하고 원문·화자를 보존한다. 각 문장은 하나의 의미 장면(scene)에 소속되며 한 장면에는 여러 발화와 여러 샷이 올 수 있다. 의미 장면은 사건과 시간·공간의 연속성으로 나눈다.

사용자가 정한 제작 출발값은 10초 생성에 약 2~3문장당 한 프롬프트다. 같은 장소와 이어지는 행동은 우선 묶어 불필요하게 생성 장면이 늘어나지 않게 한다. 이는 고정 문장 수가 아니라 초안 묶음 기준이다. 실제 낭독 시간, 대사 사이의 쉼, 동작의 시작과 결과를 확인해 조정한다. 문장마다 자동으로 새 프롬프트를 만들거나, 긴 문장을 억지로 10초에 밀어 넣거나, 묶음 수를 맞추려고 대본 원문을 바꾸지 않는다. 10초는 현재 사용자의 제작 계획이며 실행 전 모델·모드의 지원 길이를 실제 UI에서 확인한다.

샷과 발화는 시간 관계로 연결한다. 한 발화가 여러 샷에 걸치거나 한 샷에 여러 발화가 있어도 된다. 무음 액션 샷은 scene_id와 근거 사건을 갖고, 원문을 중복 낭독하지 않는다. 문장 소유권과 화면에 걸친 발화의 참조 관계를 구별한다. 전체 원고의 문장 포함 여부와 전체 타임라인의 의도하지 않은 공백을 각각 검사한다.

샷마다 다음을 기록한다: shot_id, scene_id, order_index, 연결 발화·음성 시각, 관객이 알아야 할 사건/감정, 장소·시간·인물 상태, 시작 상태, 동작의 진행, 종료 상태, 시작/종료 이미지 ID와 해시, 카메라·시선·이동 방향, 다음 샷 연결 방식. 편집 순번은 바뀔 수 있지만 식별 ID는 재번호하지 않는다.

## 시작·종료 프레임 연결

같은 행동을 이어가는 샷은 실제로 선택한 키프레임 자산을 공유한다. K01→K02, K02→K03처럼 연결하며 같은 이미지 설명문만 복사해 서로 다른 그림을 연결점으로 사용하지 않는다. 키프레임은 해당 순간의 상태이고 영상 프롬프트는 두 실제 이미지 사이의 행동이다. 이미지를 생성한 뒤 실제 그림을 보고 영상 지시를 작성·수정한다.

달리기·회전·검술은 대본의 동작과 감정에 필요한 단계별 프레임을 설계한다. 모든 동작을 한 클립에 압축하거나 반대로 모든 동작을 기계적으로 잘게 자르지 않는다. 인물의 의도와 액션의 흐름이 보이는 길이를 선택한다. 대화 상대 전환, 반응, 시간·장소 전환은 필요에 따라 컷으로 연결하되 시선·축·위치·동작을 이어 준다. 인물 간 얼굴 변형을 정상적인 카메라 전환으로 처리하지 않는다.

연결 이미지가 같아도 중간 얼굴·몸·무기나 경계의 속도·방향이 맞는지 따로 확인한다. 첫·끝 프레임의 일치만으로 성공을 선언하지 않는다. 얼굴을 숨기는 구도나 스틸로 바꾸는 일을 액션 오류의 기본 해결책으로 삼지 않는다. 실제 캐릭터로 달리기·고개 회전·검술·표정 연기를 시험하고 실패 조건에 맞춰 샷을 수정한다. Omni에서 그 실패가 발생한다고 시험 전에 단정하지 않는다.

## 생성과 검수

대표 제작 시험은 대사·표정과 연속 액션을 포함한다. 원본 얼굴과 시작/중간/끝 프레임, 동작 전환 순간을 대조하고 완성 클립을 재생한다. 얼굴 검사 자동화는 후보 선별용이며 유사도 점수만으로 통과시키지 않는다. 칼의 주인·수량·쥔 손·부상·복장, 접촉과 피격 결과도 대본과 맞춘다.

선택 키프레임을 바꾸면 그 키프레임을 사용하는 앞뒤 영상 작업을 무효화한다. 생성 중 깨진 얼굴을 새 캐릭터 정본으로 채택해 다음 영상에 누적 전파하지 않는다. 각 샷의 오류와 재생성 결과를 기록한다. 영상 제작 시험이 성공하기 전 연속성과 얼굴 보존을 보장하지 않는다.
