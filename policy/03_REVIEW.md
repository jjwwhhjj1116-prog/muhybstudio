# 대본 검수 — 최초 지침 복원

[최초 작성 지침](../reference/장편무협_대본지침_V12_FULL.md)의 대사 생존 심사, 자연 발화, 어휘·호흡·TTS·구조·연속성 검수와 [통합 검수](../stages/04_SCRIPT_FULL_AUDIT.md)를 적용한다. V13에서 원본의 문체·대사 검수 규칙을 폐기하거나 선택 사항으로 바꾼 지침은 철회했다.

검수는 원문과 근거를 비교한다. 변경 위치, 문제, 최소 수정, 수정 결과를 별도 보고서에 기록한다. 기존 작품 사실과 인물의 오해·거짓말을 구별하며, 검수하지 않은 초안을 정본 기억으로 확정하지 않는다.

실제 낭독 전 텍스트 검수와 음성 청취를 구별한다. JSON·형식·해시 검증만으로 문학적 재미나 영상 품질을 검증했다고 표시하지 않는다. 본문에 검수표·작업 설명을 섞지 않는다.
