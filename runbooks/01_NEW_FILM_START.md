# 런북: 새 무협영화 시작

1. Git 최신 승인 태그를 체크아웃한다.
2. 프로젝트 템플릿을 복제한다.
3. Docs URL과 작품 아이디어를 정본 등록한다.
4. `stages/01_SYNOPSIS_CONTEXT.md`로 시놉시스·설정집·21청크 지도를 만든다.
5. 승인 후 `stages/02_SCRIPT_PREFLIGHT.md`와 `03_SCRIPT_CHUNK.md`로 대본을 21청크 작성한다.
6. 청크 5·10·15·20 뒤 누적 감사를 하고 21 뒤 전수 감사를 한다.
7. 주요 인물만 분류해 캐릭터시트와 Medium 이미지를 생성한다.
8. 대본 문장 ID와 장면 분할 지도를 만든다.
9. 시각화 21청크를 승인 질문 없이 별도 쓰기 요청으로 누적한다.
10. 전수 매핑 감사 뒤 Flow·영상·메타데이터를 생성한다.
11. 최종 1대1 감사 뒤 릴리스한다.
