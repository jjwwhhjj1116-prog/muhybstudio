# 단계 02A. 대본 사전 잠금

## 읽기

`reference/장편무협_대본지침_V12_FULL.md`, 작품 컨텍스트, 승인 시놉시스, 고정 대사 위치표, 21청크 지도를 실제로 읽는다.

## 전체 구조 잠금

- `## Hook`: 초반 약 2분, 전편 1회.
- `[CTA]`: Hook 마지막 직접 대사 직후 단독 한 줄, 전편 1회. 무음 구분자이며 구독·좋아요 문장 금지.
- `## Intro`: Hook 뒤, 전편 1회.
- `## Body`: 전편 본편, 1회.
- `## Climax`: 최종 선택·대가·관계·복선 충돌, 1회.
- `[END]`: Climax가 끝난 뒤 `## End` 직전 단독 한 줄, 1회.
- `## End`: 후일담과 대가 정리. 마지막 내용 줄은 직접 대사이고 뒤에 본문 없음.

Hook 첫 내용 줄, Hook 마지막 내용 줄, Intro 첫 내용 줄, Intro 마지막 내용 줄, End 마지막 내용 줄은 직접 대사로 잠근다.

## 문체 잠금

- 나레이션은 감정을 가진 영화의 동행자다. 보이는 행동을 건조하게 나열하지 않는다.
- 속마음을 정답처럼 미리 폭로하지 않는다.
- 사람을 주어로 두고 구체적인 행동 동사를 쓴다.
- 사건·감정·시간 표지·결론을 인접 문장에서 반복하지 않는다.
- 문법상 완결만을 위해 대사를 토막 내지 않는다.
- 무협 말투는 어휘, 위계, 호칭, 관계와 선택에서 만들며 고풍 어미를 억지로 붙이지 않는다.

## 대사 형식

`[화자명|감정]"대사"`

허용 감정: `내추럴`, `화남`, `슬픔`, `기쁨`, `행복`, `놀람`, `FIRM`. `FIRM`은 남자 주인공의 결의·중심 선언·결정적 응답·초식에만 사용한다.

## 출력 준비

청크별 목표 글자 수, 시작 상태, 종료 상태, 고정 대사, 허용 능력 사용, 사망, 관계 변화, 금지 선행 정보를 표로 만든다.
