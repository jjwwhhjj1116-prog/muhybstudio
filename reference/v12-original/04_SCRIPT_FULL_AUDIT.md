# 단계 03. 대본 통합·전수 감사

## 통합

청크 번호는 관리 정보로 유지하되 TTS 내보내기에서 제거할 수 있다. 본문 순서는 01~21이며 중복 접합 문장과 잘린 문장이 없어야 한다.

## 구조 감사

- Hook, CTA, Intro, Body, Climax, END, End의 전역 개수와 순서
- 고정 직접 대사 5개 위치
- 마지막 대사 뒤 본문 0
- 중간 Hook·Intro·CTA·End 0

## 언어 감사

- 대사 형식 위반 0
- 남주 외 FIRM 0
- 화법·호칭·위계·관계에 어울리지 않는 현대 구어와 억지 고풍체 0
- 설명 대사, 독백형 정보 덤프, 인접 반복, 보고문 나레이션 0
- 문장 파편 때문에 대화가 부자연스러운 사례 0

## 연속성 감사

인물별 나이, 생존, 부상, 체력, 마비, 중독, 붕대, 젖음, 무기 수량, 검집, 소유권, 소지품, 인지 범위, 관계 단계, 능력 사용 횟수와 대가, 장소·시간, 복선 회수를 전수 대조한다.

## 완료 조건

총 분량 범위 통과, 구조·언어·연속성 차단 오류 0, 통합본 해시와 승인 상태 저장. 이 단계가 APPROVED여야 인물 분류를 시작한다.
