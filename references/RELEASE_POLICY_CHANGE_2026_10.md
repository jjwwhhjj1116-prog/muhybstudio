# 2026-10 신작 편성 개정과 전체 지침 읽는 순서

이 문서는 3.1.0 당시의 개정 기록이다. 이후 사용자 지시로 신작 기본값을 내부 16부×약 20분→공개 4화×80분·회차당 200장면 이하 및 두 제작 버전으로 보완했다. 현행 기준은 [3.2 개정 범위](CREATIVE_POLICY_CHANGE_3_2.md)와 VERSION.json을 따른다. 아래 역사 기록의 시간·버전·단일 제작 등식을 현행 두 버전에 중복 적용하지 않는다.

워크플로우 3.1.0은 다음 신작의 시놉시스부터 적용한다. 이전 작품의 완결 상태와 승인 대본·제작자료는 유지한다. 3.0.0 전체 기준본과 V12 원본은 기록용이며 현행 지침과 동시에 적용하지 않는다.

## 바뀐 것

| 항목 | 이전 기본값 | 다음 신작 기준 |
|---|---|---|
| 공개 편성 | 16회×약 15분 | 4화, 각 최종 실측 3,600초 이상 |
| 서사 설계 | 공개 회차와 내부 번호가 혼용될 여지 | 내부 16부를 네 부씩 공개 4화에 배정 |
| 기술 청크 | 상위 21개 고정 | 장면·대화 경계와 작업량으로 별도 계획; 미정은 null |
| 구조·CTA·직접 대사 엔딩 | 회차 범위가 불명확 | 공개 회차 전체에 한 벌; 내부 부·청크에서 반복하지 않음 |
| 최종화 | 기본 16회 종료 | 신작 공개 4화에서 중심 갈등·관계·대가 종결 |
| 시간 확인 | 15분 목표 | 계획/예상/실측 구분; 글자 수와 클립 합만으로 통과하지 않음 |
| 시놉시스 지침 | 기억 지침의 개요 중심 | 시즌 약속·무협 재미·세계관·4화 편성·16부 사건·회수 연결 |
| 개정 적용 | 기존 작품 이행 여지 | 새 프로젝트만 초기화; 기존 정본 자동 변경 없음 |

개요·초기 서식에 남은 이전 영상 모델 표기는 현재 선택인 Veo 3.1 - Lite로 정리한다. 영상 모델 변경이나 신규 기능 확인을 의미하지 않는다. 내부 키프레임·작업 수와 납품 장면 수를 구별하되 시각화 N=이미지 N=영상 N 계약은 유지한다.

## 유지한 것

소설형 낭독 나레이션, 감정이 살아 있는 영화체 호흡, 무협의 위세와 격정, 포인트 대사, `[화자명|감정]"대사"`, 공개 회차의 마지막 직접 대사, 설정 근거와 외부 기억, 사용자 예시의 복제 금지, 기존 한국 다크판타지 무협 웹툰 화풍, 실제 캐릭터시트와 동일 이름의 Flow 캐릭터 등록, 장면 분할 후 시각화, 편집기 3줄 입력, 제목·설명란·타임라인·썸네일, 원본 보존과 Git 공유를 유지한다.

글자 수·대사 비율·어미 횟수 등 새 창작 통제표를 추가하지 않는다. 일곱 무협 재미 관점은 기획을 점검하기 위한 질문이고 매 장면의 할당표가 아니다. 검수 점수는 실제 구절과 수정 근거가 있는 편집 평가이며 흥행 보장이 아니다.

## 전체 세트의 읽는 순서

1. AGENTS.md → workflow/00_BOOT_SEQUENCE.md → workflow/12_THREE_PC_SYNC.md → coordination/STATUS.md: 현재 버전·권한·공유·재개 상태.
2. policy/07_SYNOPSIS_AND_RELEASE_PLAN.md → policy/02_STORY_MEMORY.md → stages/01_SYNOPSIS_CONTEXT.md: 신작 시놉시스·세계관·인물·배분·기억.
3. policy/01_WRITING.md → contracts/01_SCRIPT_OUTPUT_CONTRACT.md → stages/02_SCRIPT_PREFLIGHT.md → policy/03_REVIEW.md: 집필·형식·글쓰기 개선·검수.
4. contracts/05_CHARACTER_IMAGE_CONTRACT.md → stages/05~07 → policy/04_CONTINUOUS_ANIMATION.md → stages/08~10 → contracts/02~03: 캐릭터·장면 분할·시각화·대응 검수.
5. policy/05_FLOW_EXECUTION.md → stages/11~12 → workflow/13_SCRIPT_TO_PROMPTS.md: 프롬프트 추출·프로젝트·캐릭터 등록·실제 생성 검증.
6. policy/06_DELIVERY.md → stages/13~14 → contracts/04_GOOGLE_DOCS_CONTRACT.md: 음성·편집·제목·썸네일·설명·예상/실제 타임라인·납품.
7. 나머지 workflow·runbooks·templates·schemas·automation·tests: 복구·무효화·일괄 실행·초기화·검증 도구. reference의 V12 원본과 legacy 도구는 현행 실행 기준에서 제외한다.

모든 지침을 매 청크마다 주입하지 않는다. 집필에는 현행 문체·형식·해당 작품 사실과 이번 범위를 읽고, 영상·포장·운영의 상세 문서는 그 단계에 사용한다. 전체 세트는 찾기 위한 자료이며 장편을 딱딱하게 만드는 누적 프롬프트가 아니다.
