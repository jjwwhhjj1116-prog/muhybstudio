# 3.2 개정 범위와 개선 10안 대응

2026-10-09. 사용자 지시로 다음 신작부터 적용한다. 완료 작품·승인 원고·기존 유료 자산과 Docs는 변경하지 않는다. 이전 진단 문서의 세분한 12개 번호와 대화에서 제시한 압축 10개 번호를 혼동하지 않는다. 이번 승인은 아래 시놉시스 1~6, 대본 7~10의 적용이다.

## 시놉시스 1~6

| 번호 | 적용한 개선 | 작성·검수에서 확인할 것 |
|---|---|---|
| 1 | 이야기의 구체적인 약속과 훅 | 주인공이 겪을 갈등·특이한 능력·기대 보상이 본편에서 실제 실현되는가 |
| 2 | 선택→버린 길→결과 | 더 쉬운 대안과 위험을 알고 한 결정이 다음 사건의 원인이 되는가 |
| 3 | 상대의 대응 | 악역도 아는 정보·목표·권한으로 전략을 바꾸고 주인공의 성공을 방해하는가 |
| 4 | 기연·무공의 실효 | 보상을 얻은 뒤 실제 싸움·협상·판단이 바뀌고 한계와 대가가 지속되는가 |
| 5 | 부분 답과 보상 | 모든 답을 마지막으로 미루지 않고 중간에도 확인 가능한 진실·성과·관계 변화가 있는가 |
| 6 | 인물·세계관이 만드는 사건 | 각자의 욕망·강호의 규칙·문파와 세가의 이해가 충돌을 만들어 내는가 |

적용 문서: policy/07, creative-guides/01, stages/01. 공통 사건·설정은 두 제작 버전에 공유하며 설정 목록이나 재미 요소의 이름을 붙인 것만으로 본문 구현을 대신하지 않는다.

## 대본 7~10

| 번호 | 적용한 개선 | 작성·검수에서 확인할 것 |
|---|---|---|
| 7 | 현재 장면에 필요한 나레이션 | 위세·위험·기대·감정을 움직이는 설명인가. 무협의 격정과 장엄함은 살리는가 |
| 8 | 상대에게 작용하는 대사 | 위협·거절·회유·결단 등이 상대 반응과 관계를 바꾸는가. 감정 태그가 실제 말과 맞는가 |
| 9 | 감정과 관계의 지속 | 상실·의심·부채·신뢰의 후유증이 다음 행동에 남는가 |
| 10 | 청취 호흡과 계획의 본문 구현 | 문단의 연결·주어·행동 순서가 자연스럽고 중요한 선택·기연·반전이 실제 장면으로 구현됐는가 |

적용 문서: policy/01·03, creative-guides/02, stages/02~04, contracts/01. 원문 근거와 실제 약점을 보고 수정하며 임의의 ‘90점’으로 통과시키지 않는다. 어미 금지·대사 비율·문장 길이·반전 간격을 새 수치 규칙으로 만들지 않는다. 소설형 나레이션과 `[화자명|감정]"대사"`, 공개 직접 대사 엔딩은 보존한다.

## 편성과 두 제작 버전

- 내부 16부×약 20분을 네 부씩 공개 4화×80분으로 편성한다. 공개 회차당 목표·최종 실측 기준 4,800초, 의미 장면 200개 이하다.
- 2~3문장을 한 의미 장면으로 묶는 것을 초기 기준으로 삼되 시간·공간·행동 변화를 대조한다. 200개를 맞추려고 원문을 줄이거나 모순된 순간을 한 이미지에 강제로 넣지 않는다.
- 기존 소설판 NOVEL: N=이미지 N=Flow 영상 N. 신규 실험 웹툰판 WEBTOON_EXPERIMENT: N=기본 이미지 N=모션 계획 N, 선택 Flow 영상 K≤N. 생성 영상은 원래 장면 ID를 쓴다.
- 같은 이야기의 주요 선택·결과·관계·결말은 공통이며 대본·발화·장면·음성·편집·포장 파일은 버전별로 관리한다. 실험 웹툰판은 후편집 말풍선과 반응 컷을 사용하고 이미지만으로 80분 재미가 검증됐다고 하지 않는다.
- Flow 프롬프트는 실제 참조 이미지에 맞춘 짧은 한 동작·한 카메라로 시작한다. 비노골적인 표현과 원래 장면 맥락을 유지하며 정책 우회나 성공 보장은 하지 않는다. 이미지 자체가 원인일 수도 있다.

80분에 200장면이면 평균 표시 길이는 24초 이상이다. Lite의 짧은 생성 길이와 같지 않다. 편집·실측을 따로 계획하며 자동 무한 반복·과도한 감속으로 시간을 채우지 않는다.

## 구현과 확인 범위

3.2 초기 서식과 검증기는 제작 버전·배분·시간·200 상한·선언된 수량 계약을 검사한다. 3.0/3.1 서식의 기존 배분은 보존한다. 실제 대본의 문학성, 모든 장면 내용, TTS 실측, 미디어 생성, Flow 캐릭터 등록, 웹툰 모션/말풍선 렌더와 조회수는 이 검사로 확인되지 않는다. Flow MCP 조사 결과는 references/FLOW_INTEGRATION_OPTIONS_2026_10.md에 별도로 둔다.
