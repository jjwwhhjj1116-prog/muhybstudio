# 웹툰판 대본 작업·전달 메모 — 빈 서식

이 파일은 비낭독 관리 자료다. 작품별 값은 공개 저장소 밖 비공개 프로젝트에 작성한다. 정본·설정·초안·대사·프롬프트를 이 공통 빈 서식에 채워 커밋하지 않는다. 낭독 대본은 별도 UTF-8 파일이며 [전용 지침](../policy/09_WEBTOON_WRITING.md)을 따른다.

## 범위와 근거

- production_version: WEBTOON_EXPERIMENT
- 공개 회차 / 내부 부 범위 / 기술 집필 범위: 미정
- 공통 정본·시놉시스 버전과 해시: 미정
- 관련 설정 원문 / 사용자 참고 구간 / 잠금: 미정
- 직전 웹툰 원문·공방 / 시작 인지·부상·무기·감정: 미정
- 이번 결과와 다음 시작 상태: 미정
- 초안·개선·확정 원고 경로와 해시 / 수용 상태: 미정
- 예상 낭독 시간·산출 근거: 미정
- 실제 TTS·최종 렌더 시간 / 증거 / 청취·시각 검수: 미확인

## 공통 사건의 전달 대응

필요한 사건만 기록한다. 모든 문장에 작성하거나 이 순서를 본문의 사건 공식으로 강제하지 않는다. 실제 발화 ID는 원문에서 연결하고 미부여 상태에는 임의 ID를 만들지 않는다.

| 공통 사건 ID·원문 근거 | 중요한 선택·상대 반응·결과 | 낭독 대본의 위치·발화 | 화면에만 맡긴 사실·무음 반응 | 필요한 그림·식별 조건·전달 의도 | 준비 상태·누락·제안 변경 |
|---|---|---|---|---|---|

확정 이전에는 scene_id·시각화 프롬프트·실제 초 단위 타이밍을 확정하지 않는다. 연결 발화가 없는 독립 무음 구간은 앞뒤 원고 위치와 공통 사건 ID를 남기며 가짜 발화·문장 ID를 만들지 않는다. 새 사건·시간·장소라면 장면 N에 포함한다. 기존 원문 추출기의 독립 무음 장면 지원을 가정하지 않는다. 준비 상태는 텍스트 계획/자산 확보/실제 검수 등을 구별한다. 화면에 맡긴 사실은 후속 장면표에 연결하고 실제 이미지에서 식별되는지 확인한다.

## 글쓰기 개선과 통합 검수

| 본문 근거 위치 | 발견한 문제·독자에게 주는 영향 | 수정 이유·개선본 위치 | 영향받는 상태·정본 대조 | 재검토 결과·남은 미확인 |
|---|---|---|---|---|

설정·형식 오류와 문학적 판단을 구분한다. 네 부를 이어 읽었는지, 공개 마지막 직접 대사 이후 낭독 나레이션이 없는지 기록한다. 점수를 요청받으면 같은 공통 척도로 전후 근거를 평가하며 듣지 않은 음성·보지 않은 그림을 통과로 표시하지 않는다.

## 확정 후 후속 연결

- 승인 인물·지속 상태 / 캐릭터시트 근거: 미정
- 장면 분할표 / N≤200 검토: 미정
- 기본 원화 N / 모션 계획 N / 선택 Flow K / 별도 보조 자산 수: 미정
- 장면표에 이관할 화면 전달 메모 / 누락 확인: 미정
- 다음 작업·의존 입력·담당 범위: 미정

수량 미정과0을 구별한다. 전달 메모를 낭독 대본이나 시각화 편집기 입력에 붙이지 않는다. 공개 지침의 테스트 통과와 작품의 확정·자산·음성·영상 완료는 서로 다른 상태다.
