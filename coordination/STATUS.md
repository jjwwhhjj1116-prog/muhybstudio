# 공통 워크플로우 상태

업데이트: 2026-09-06. 기준: workflow 3.0.0 / 작가 V13. 이 파일은 공개 가능한 범용 작업 상태다.

## 반영된 방향

- 집필은 짧은 지침과 해당 장면의 사실·직전 본문으로 진행한다.
- 원문 근거로 인과·발화를 따로 검수하고, 검수한 사실만 작품 기억에 확정한다.
- 기존 웹툰 디자인을 유지하며 시작·종료 프레임과 실제 동작이 이어지는 무협 애니메이션을 목표로 한다.
- Flow 이미지/영상 생성·다운로드·QA·음성·편집까지 전체 자동화를 구현 범위로 둔다.
- main을 세 PC의 공통 기준으로 사용하고 작업 종료 시 검증·커밋·푸시·원격 확인한다.

## 음성 경로 확인

2026-09-06 공식 문서 확인: Flow 음성 참조는 Ingredients 전용이며 Frames와의 동시 사용을 가정하지 않는다. 별도 Gemini TTS와 ElevenAPI 요금 비교, 지문/낭독 분리, 발화 캐시·부분 재생성 기준을 policy/06_DELIVERY.md와 references/VOICE_OPTIONS_2026_09.md에 반영했다. 실제 계정 시험·음성 생성·어댑터 구현은 아직이다.

## 다음 작업

이번 로컬 검증: 문서/템플릿/공개 파일 검사 통과, 프로젝트 초기화·동기화 회귀 테스트 10개 통과. 두 로컬 clone으로 최신 변경 수신, 수정 파일 보존, 분기된 이력 보존, 잘못된 원격 차단을 확인했다. 실제 다른 두 PC의 설치·실행까지 확인한 것은 아니다. 원격 CI 결과는 GitHub Actions에서 확인한다.

1. 별도 비공개 프로젝트 저장 위치/동기화 경로를 연결한다.
2. 새 시리즈의 작품 정본과 기억을 원문 근거로 구축한다.
3. 실제 Flow UI와 자산 식별을 검증하고 생성·회수 큐를 구현한다.
4. 실제 캐릭터의 연속 액션·표정 시험, TTS/편집 연결을 진행한다.

완료 여부는 실제 파일과 검증 증거로 갱신한다. 최신 커밋은 Git 이력과 원격 main으로 확인한다. 셀프 참조하는 커밋 SHA를 이 파일에 미리 만들어 적지 않는다.
