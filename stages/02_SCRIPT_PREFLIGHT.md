# 단계 02A. 집필 사전 확인

1. [현행 집필 지침](../policy/01_WRITING.md), [출력 계약](../contracts/01_SCRIPT_OUTPUT_CONTRACT.md), 작품 컨텍스트·시놉시스와 관련 설정 원문을 읽는다. 연결된 비공개 사용자 예시와 해설도 읽고 출처·해시를 기록한다. 옛 V12의 금지표를 동시에 적용하지 않는다.
2. 실제 회차 요청인지 기술 청크 요청인지 확인한다. 현재 작품 지도에서 범위·시작과 종료 상태·러닝타임 목표를 읽는다. 기존 장편의 전체 분량과 21청크 수를 새 회차에 강제하지 않는다.
3. 인물의 위세와 관계, 당면 욕망과 방해, 선택의 결과, 독자가 궁금해할 것을 간결하게 잡는다. 회차 End는 다음 전개를 기대하게 하는 직접 대사로 끝내도록 준비한다. 그 밖의 대사 위치·개수를 미리 할당하지 않는다. 사용자가 이미 잠근 특정 대사는 유지한다.
4. 원문 근거로 인물의 지식·오해·거짓말, 부상·무기·소지품·능력 비용·이동 시간을 확인한다. 새 설정이나 사건 순서 변경이 필요하면 proposed 근거를 기록한다.
5. 직접 대사의 화자명·감정, 낭독 나레이션, 제작 표식의 형식을 확인한다. 집필 계획과 검수 장부는 본문 밖에 둔다.
