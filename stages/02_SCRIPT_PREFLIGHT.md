# 단계 02A. 집필 사전 확인

1. [현행 집필 지침](../policy/01_WRITING.md), [출력 계약](../contracts/01_SCRIPT_OUTPUT_CONTRACT.md), 작품 컨텍스트·시놉시스와 관련 설정 원문을 읽는다. 연결된 비공개 사용자 예시와 해설도 읽고 출처·해시를 기록한다. 옛 V12의 금지표를 동시에 적용하지 않는다.
2. 공개 회차·내부 부·기술 청크 중 요청 범위를 확인한다. 현재 작품의 배분 계획에서 시작/종료 상태·러닝타임 목표를 읽는다. 신작은 내부 16부를 네 부씩 공개 4화에 배정하고 공개 회차마다 실측 3,600초 이상을 목표로 한다. 기술 청크 수는 따로 계획하며 기존 21개를 강제하지 않는다. 기존 작품에는 기존 승인 배분을 적용한다.
3. 인물의 위세와 관계, 당면 욕망과 방해, 선택의 결과, 독자가 궁금해할 것을 간결하게 잡는다. 공개 회차의 구조와 CTA/END는 한 벌이며 부·청크에서 반복하지 않는다. 중간 공개 End는 다음 전개의 기대, 최종 공개 End는 전체 이야기의 회수를 주는 직접 대사로 준비한다. 그 밖의 대사 위치·개수를 미리 할당하지 않는다. 사용자가 이미 잠근 특정 대사는 유지한다.
4. 원문 근거로 인물의 지식·오해·거짓말, 부상·무기·소지품·능력 비용·이동 시간을 확인한다. 새 설정이나 사건 순서 변경이 필요하면 proposed 근거를 기록한다.
5. 직접 대사의 화자명·감정, 낭독 나레이션, 제작 표식의 형식을 확인한다. 집필 계획과 검수 장부는 본문 밖에 둔다.
