# 분할된 장면에 맞는 시각화 프롬프트

[장면 분할](08_VISUAL_PREPROCESS.md)의 저장본을 입력으로 삼는다. [연속 영상 정책](../policy/04_CONTINUOUS_ANIMATION.md)을 함께 적용한다.

제작 버전별 승인 대본·해시·장면표를 확인한다. `NOVEL`(기존 무협소설, 기본값)과 `WEBTOON_EXPERIMENT`(신규 무협웹툰 실험)은 세계관·인물·주요 인과·결말을 공유해도 파생 파일을 분리한다. 다음 신작은 내부 네 부를 합친 공개 한 화 약 80분·4,800초, 총 N≤200이며 기존 승인 작품은 자동 변경하지 않는다.

웹툰판은 확정 뒤 장면표에 이관된 화면 전달 메모도 입력으로 읽고 사건 근거·인물 상태·단서의 식별 조건을 프롬프트와 필요한 자산에 반영한다. 해당 메모를 `[한국어 번역]`의 낭독 원문에 덧붙이지 않는다. 독립 무음 장면의 구조 매핑은 별도로 기록하며 기존 추출기의 자동 지원을 가정하지 않는다. 표시 규격을 임의로 꾸미거나 발화 원문을 만들어 미지원 상태를 숨기지 않는다.

## 전달 형식

```text
[장면 N]
[한국어 번역] 해당 장면의 대본 원문 — 나레이션과 감정 태그·큰따옴표 대사 모두 보존
[영어 이미지 프롬프트] 그 장면의 한 순간을 그리는 완결된 영어 프롬프트
```

**편집기 입력 규격:** 장면마다 위 3줄을 연속으로 쓴다. `[한국어 번역]`의 대본은 한 물리적 줄이어야 한다. 원문의 문단·줄바꿈은 공백 하나로 연결하며, 문구·구두점·감정 태그·큰따옴표는 바꾸지 않는다. `[한국어 번역]`과 `[영어 이미지 프롬프트]` 사이 빈 줄·단독 대본 줄을 넣지 않는다. 장면 사이에만 빈 줄 하나를 둔다. 화면 자동 줄바꿈은 파일의 실제 개행과 다르다. 원본 대본·근거 JSON은 원래 문단을 보존한다.

CTA는 Hook 마지막 장면 뒤, END는 End 첫 장면 앞에 각각 원본 표식을 유지한다. 해당 버전의 공개 회차 전체에 한 번 적용하며 내부 부·청크마다 반복하지 않는다. 표식에 장면 번호를 부여하지 않는다. 분석·시작종료 프레임·동작 초안은 별도 파일에 둔다.

NOVEL은 시각화 N=이미지 N=Flow 영상 N, 웹툰은 시각화 N=기본 이미지 N=모션 편집 계획 N으로 1~N 번호가 일치한다. 웹툰의 선택 Flow K개(K≤N)는 원래 장면 번호·ID를 유지한다. 1~K 재번호나 비선택 장면의 빈 영상 항목으로 수량을 꾸미지 않는다. 후속 A/B/C 생성 컷으로 수량을 늘리지 않으며 분할을 바꾸면 해당 버전 원문 구간과 모든 기본·선택 목록을 함께 개정해 200 상한을 확인한다. 충돌을 원문 삭제·거대한 문장 재작성으로 해결하지 않는다.

## 화풍과 장면 내용

한국 다크판타지 무협 액션 웹툰의 원래 화풍을 유지한다. 공통 화풍 문구는 다음 요소를 생략하거나 일반 웹툰으로 임의 약화하지 않는다.

`Korean dark-fantasy martial-arts action manhwa webtoon style, hand-drawn illustration, ink line art with digital coloring, NOT photorealistic, NOT 3D render, NOT photograph, Masterpiece, ultra-detailed, premium anime key-visual quality, cel-shaded digital painting with ink brush texture, rich ink-wash rendering with dramatic lighting.`

불꽃·입자·바람은 실제 장면에 필요한 경우에 추가한다. 인물의 표정과 행동은 분할 원문의 사건·감정에 근거해야 한다. 의상·무기·쥔 손·부상·젖음·구속·소품 소유권은 각 순간에 맞게 명시한다. 칼을 집어넣었다고 손이 항상 비어 있다고 가정하지 않는다. 구조·부축·열쇠 조작 등 그 손이 실제로 하는 행동과 대조한다.

승인된 인물의 이름·디자인을 유지한다. 실제 단일 이미지 참조의 등록 여부는 별도 기록하며, 이름만 넣고 등록 완료라고 표시하지 않는다. 상세 시트의 이름·칸·종이 배경을 장면에 옮기지 않는다. 화면 가장자리까지 이어지는 단일 중국 강호 배경으로 작성한다.

두 버전의 기본 생성 이미지는 문자·말풍선·테두리·격자 없는 깨끗한 16:9 단일 화면이다. 웹툰의 말풍선·타이포·선택적인 판넬 경계는 후편집 오버레이로 구별한다. 기존 표정 참조·이미지 크롭과 새 반응 그림을 구별하고 새 그림의 원문 대응·자산 ID·해시·수량·비용을 기록한다. 좌우 반전으로 쥔 손·부상·흉터가 뒤집히지 않도록 한다. 편집 좌표·음성·모션·말풍선 기술 지시는 낭독 본문 밖에 두며 같은 대사의 말풍선·자막 중복 노출을 피한다.

노골적인 피·신체 손상·처형·죽임·살육을 화면에 확대하지 않는다. 해당 사건의 비노골적인 직전·직후 표정·시선·반응 중 단일 순간을 선택해 원문 대응표에 남긴다. 대본 원문·실제 나이·부상 지속 상태는 바꾸지 않는다. 긴 부정 목록 대신 그 순간에 보일 모습을 긍정문으로 쓴다.

## 시작·종료와 검수

Flow를 쓰는 장면에 시작·종료 상태를 설계하고, 연속 샷은 동일 종료/시작 ID 및 실제 자산을 공유한다. 입력 모드에 필요한 실제 자산을 확인하며 시작 이미지 단독 모드에서 종료 이미지를 억지로 요구하지 않는다. 웹툰 비선택 장면에는 영상 생성 상태를 꾸며 넣지 않는다. 구도·시간 전환은 CUT으로 기록한다. 그림 한 장에 시간상 전후 행동을 겹쳐 넣지 않는다.

영상은 실제 입력 순간부터 가능한 비노골적인 한 동작·표정·시선과 한 카메라를 짧게 지시한다. 완료된 행동 반복·임의 발화·복잡한 인계·다중 액션을 쌓지 않으며 별도 TTS를 쓸 경우 조용한 움직임으로 쓴다. 제한 대응은 원인별로 확인하고 단어만 지우는 우회나 오류 없는 생성을 보장하지 않는다.

8초 생성 길이와 최종 표시 시간을 별도로 계획한다. 200클립도 26분 40초이므로 약 80분 전부의 생성 움직임으로 보고하지 않는다. 이미지 유지·크롭·필요한 클립 또는 웹툰 모션 편집을 원문·음성에 맞게 배치하며 자동 Extend·3배 감속·무한 반복으로 채우지 않는다. 200장면일 때 평균 24초·약 20~30초 구간은 참고이며 강제 균일 길이가 아니다.

청크별 검수 후 다음 청크를 이어가고 공개 회차 전체·내부 부 경계를 다시 읽는다. 원문·번호·상태·화풍·버전별 수량을 검수한 영어 문구만 추출한다. 영상·표시 시간·모션 계획은 실제 입력 이미지와 TTS 대조 전까지 DRAFT이며 실제 편집·재생 검수 완료와 구별한다.
