# 단계 02B. 대본 청크 생성

## 청크 입력

- 전체 시놉시스와 해당 청크 지도
- 직전 본문의 마지막 두 행동
- 직전 상태 JSON 전체
- 이번 청크 목표 글자 수와 목표 종료 상태
- 이번 청크에서 허용된 고정 대사·능력·사망·관계 변화

## 출력 형식

```text
[청크 NN/21]
해당 대본 본문
```

본문에 계획, 사과, 검수표, 다음 청크 예고를 섞지 않는다.

## 작성 규칙

1. 직전 행동의 결과에서 바로 시작한다.
2. 재요약·재소개·새 Hook·중간 CTA·가짜 엔딩을 만들지 않는다.
3. 원인 → 욕망 → 방해 → 선택 → 대가 → 결과가 장면 안에서 이어진다.
4. 대사는 상대·목적·반응이 있는 자연 발화로 쓴다. 정보 정리문이나 작가 설명을 인물 입에 넣지 않는다.
5. 나레이션은 인물의 선택과 대가를 따라가되 장면에 없는 사실을 단정하지 않는다.
6. 부상·무기·소지품·인지·관계·능력 비용을 직전 상태에서 이어간다.
7. 분량을 채우려고 사건이나 감정을 반복하지 않는다.
8. 다음 청크 사건을 무리하게 당겨오지 않는다.

## 청크 후 처리

- 공백 포함 글자 수 계산
- 대사 태그·감정·FIRM 검사
- 구조 표식 전역 누적 개수 검사
- 마지막 두 행동과 인물 상태 저장
- 출력 해시 저장
- 5·10·15·20청크 뒤 누적 연속성 감사

차단 오류가 0이면 사용자 승인 질문 없이 다음 청크를 실행할 수 있다.
