# 단계 02B. 회차와 청크 집필

[현행 집필 지침](../policy/01_WRITING.md)과 [출력 계약](../contracts/01_SCRIPT_OUTPUT_CONTRACT.md)을 적용한다. 입력은 이번 범위의 시놉시스·관련 설정·직전 완결 장면·현재 인물 상태·연결된 비공개 예시다.

제작 버전을 먼저 확인한다. 무협소설은 기존 소설형 전달을 유지하고 무협웹툰 실험은 현장 공방 중심의 별도 원고로 집필한다. 공통 핵심 선택·결과·관계·결말을 바꾸지 않으며 원소설 설명을 그대로 대사로 치환하지 않는다. 원고 해시·부·문장·장면 매핑은 버전별로 독립 관리한다.

- 나레이션은 지금 이해·위험·격·기대·감정에 필요한 정보를 담고 인물의 위세를 쌓는다. 중요한 대사는 상대에게 무엇을 얻거나 막거나 숨기려는지, 준비 공방과 반응까지 읽는다. 감정 태그·큰따옴표를 보존하며 대사 수·비율을 할당하지 않는다.
- 핵심 선택·상대 반응·결과·보상을 실제 본문으로 구현하고 승패·큰 말 뒤의 감정과 관계가 다음 행동에 남게 한다. 이름·정체·위협·상실을 체감할 호흡도 남기며 모든 문장을 행동 보고로 바꾸거나 같은 길이로 끊지 않는다.
- 다음 청크는 직전 결과에서 이어 쓴다. 청크마다 재소개·재요약·새 Hook·CTA·가짜 엔딩을 만들지 않는다. 실제 회차 경계는 작품 지도에 따른다.
- 문장·공방·공격과 결과를 분량 때문에 중간에서 끊지 않는다. 문학적 어휘·문장 수치는 강제하지 않는다.
- 신작의 부당 약 20분·공개화 목표 80분은 작업 청크의 고정 길이가 아니다. 기술 청크는 가변이며 목표·예상 낭독·실제 음성 길이를 구별한다.
- 본문 완성 뒤 인과·발화·호흡을 검수하고 원문 근거·변경·해시·다음 상태를 별도 파일에 기록한다. 설정 변경은 확인 전 정본으로 승격하지 않는다.
- 사용자에게 허용된 작성 범위 안에서는 청크마다 재승인을 요구하지 않는다. 검수 통과와 사용자 수용, 실제 음성 검증은 구분한다.
