# 장면 분할 — 시각화 집필 전에 완료

현행 정책은 [연속 영상](../policy/04_CONTINUOUS_ANIMATION.md), 전체 순서는 [대본에서 프롬프트까지](../workflow/13_SCRIPT_TO_PROMPTS.md)를 따른다.

1. 확정 대본 해시와 사용자 승인 캐릭터 디자인 파일·해시를 확인한다. 상세 시트 승인과 Flow 단일 이미지 등록 완료를 구별한다.
2. 나레이션·직접 대사 원문에 안정적인 문장 ID와 위치를 부여한다. 감정 태그와 큰따옴표는 전달용 원문에서 보존한다.
3. 같은 장소·시간·시점·행동의 약 2~3문장을 10초 생성의 출발값으로 묶는다. 전환·반응·긴 대사는 의미에 맞춰 예외를 둔다. 대본을 길이에 맞춰 다시 쓰지 않는다.
4. 장면별 원문, 분할 이유, 사건·감정, 인물 상태, 배경, 카메라, 시작·진행·종료와 연결 방식을 기록한다.
5. 전체 원문 포함, 문장 소유권의 누락·중복·역순, 발화 누락을 검사하고 장면표를 먼저 저장한다. 그 뒤 영어 프롬프트 집필로 넘어간다.

기존 장면표가 있으면 원문과 대조해 유지·수정 근거를 남긴다. 검수한 분할을 이유 없이 처음부터 다시 만들지 않는다. 실제 TTS 전에는 최종 시간이나 영상 수를 확정하지 않는다.
