# 장면 분할 — 시각화 집필 전에 완료

현행 정책은 [연속 영상](../policy/04_CONTINUOUS_ANIMATION.md), 전체 순서는 [대본에서 프롬프트까지](../workflow/13_SCRIPT_TO_PROMPTS.md)를 따른다.

1. 제작 버전 `NOVEL`(기존 무협소설, 기본값) 또는 `WEBTOON_EXPERIMENT`(신규 무협웹툰 실험), 해당 버전 확정 대본·해시와 승인 캐릭터 디자인 파일·해시를 확인한다. 두 버전의 정본은 공유해도 승인 원고·분할·프롬프트·편집·제목 파일은 혼용하지 않는다. 상세 시트 승인과 Flow 등록 완료·실제 장면 참조 첨부를 구별한다.
2. 나레이션·직접 대사 원문에 안정적인 문장 ID와 위치를 부여한다. 감정 태그와 큰따옴표는 전달용 원문에서 보존한다.
3. 같은 장소·시간·시점·행동의 약 2~3문장을 초기 의미 묶음으로 잡는다. 한 문장마다 자동 분할하지 않는다. 다음 신작은 내부 네 부를 합친 공개 한 화 전체 N≤200·1~N 번호로 검토한다. 초과하면 같은 장소·시간·행동의 인접 묶음 통합을 먼저 검토하고 이유를 기록한다. 원문 삭제·요약·거대한 문장 재작성이나 서로 다른 상태 중첩으로 수량을 맞추지 않는다. 의미와 전체 원문을 유지한 통합이 불가능하면 충돌과 사용자 조정 필요를 남기고 임의 초과 납품하지 않는다.
4. 장면별 원문, 분할 이유, 사건·감정, 인물 상태, 배경, 카메라, 단일 대표 순간·시작·진행·종료와 연결 방식을 기록한다. 생성 클립 길이와 최종 표시 시간을 분리하고 실제 TTS가 없으면 예상으로 표시한다. 약 80분·4,800초/200장면의 평균 24초·약 20~30초 구간은 참고이며 강제 길이가 아니다. 이미지 유지·크롭·필요한 움직임 배치를 별도 계획한다.
5. 전체 원문 포함, 문장 소유권의 누락·중복·역순, 발화 누락을 검사하고 장면표를 먼저 저장한다. 그 뒤 영어 프롬프트 집필로 넘어간다.
6. NOVEL은 시각화 N=이미지 N=Flow 영상 N, 웹툰은 시각화 N=기본 이미지 N=모션 편집 계획 N으로 납품한다. 같은 1~N 번호를 사용한다. 웹툰의 선택 Flow K개(K≤N)는 훅·핵심 장면의 원래 번호·ID를 유지하며 1~K 재번호·빈 항목으로 N개를 꾸미지 않는다. 재분할하면 해당 버전의 원문 소유권과 모든 기본·선택 목록을 함께 개정하고 200 상한을 확인한다. 장면표 밖 A/B/C 생성 컷을 추가하지 않는다. 웹툰의 크롭·참조 표정 재사용과 새 그림 생성은 별도 자산 기록으로 구별한다.

8초 클립 200개는 26분 40초다. 이 계획을 약 80분 연속 생성 애니메이션으로 표시하지 않으며 자동 Extend·3배 감속·무한 반복으로 채우지 않는다. 웹툰은 선택 K개만 생성 영상으로 합산한다. 편집·말풍선·타이포·음성 기술 설명은 원고 밖에 두고 선택한 방식의 실제 완료 수준을 구별한다.

기존 장면표가 있으면 원문과 대조해 유지·수정 근거를 남긴다. 검수한 분할을 이유 없이 처음부터 다시 만들지 않으며 기존 승인 작품을 자동 재분할하지 않는다. 실제 TTS 전에는 최종 표시 시간·타이밍 검수 완료를 확정하지 않는다. 장면 수와 선택 목록은 검수한 계획으로 기록하고 변경 시 버전을 남긴다.
