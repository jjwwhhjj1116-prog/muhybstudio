[policy/05_FLOW_EXECUTION.md](../policy/05_FLOW_EXECUTION.md)

영어 텍스트 추출을 넘어 Flow 생성·선택·회수 실행 요구. 구문서를 새 지침과 함께 적용하지 않는다. 이전 내용은 Git 이력에 보존되어 있다.

1. 제작 버전·공개 회차·해당 승인 원고/프롬프트·해시·대상 프로젝트·캐릭터 등록·실제 참조 첨부를 대조한다. 기본 `NOVEL`은 N개의 장면·이미지·영상을 같은 번호로, 신규 `WEBTOON_EXPERIMENT`는 N개의 기본 이미지·모션 계획과 선택 Flow K개를 구별한다. 두 버전 모두 공개 한 화 N≤200이며 선택 K≤N은 원래 장면 번호를 유지한다.
2. 선택하지 않은 웹툰 장면에 영상 작업을 만들지 않고 빈 항목이나 1~K 재번호로 완료 수량을 꾸미지 않는다. 같은 이미지 크롭·표정 참조 재사용·새 반응 그림은 별도 자산 기록으로 구별한다. 다른 버전의 같은 번호를 가져와 입력이라고 가정하지 않는다.
3. 실제 계정 UI에서 Veo 3.1 - Lite 모델·입력 모드·화면비·길이·비용을 확인한다. 8초는 초안 출발값이며 공식 문서의 지원 안내와 이번 실제 실행 근거는 다르다. 상세 지원표·2026-10-09 확인 근거는 위 정책을 따른다.
4. 실제 입력 순간부터 가능한 비노골적인 표정·시선 또는 한 동작과 한 카메라를 짧은 긍정문으로 지시한다. 실제 참조 연결을 우선하며 고유명 반복으로 대체하지 않는다. 원문을 바꾸거나 나이를 바꾸지 않으며 완료 행동 반복·임의 발화·긴 부정 목록을 넣지 않는다. 별도 TTS라면 조용한 움직임으로 작성한다.
5. 실패는 프롬프트·이미지·음성·할당량·모델/기능·서비스 오류 등 실제 근거로 나눠 처리한다. 비노골적인 장면 해석은 제작 전략이며 모더레이션 우회나 성공 보장이 아니다. 정상 결과를 보존하고 필요한 입력만 새 버전으로 고친다.
6. 생성·선택·정확한 자산 회수·파일 검증·실제 영상 QA·재개 상태를 구별한다. 실제 이미지 또는 TTS가 없으면 영상/시간 계획은 DRAFT다. 8초×200개는 26분 40초이며 약 80분 최종 표시는 버전별 이미지·모션·음성 편집으로 따로 검사한다. 자동 Extend·3배 감속·무한 반복을 시간 충족의 기본값으로 쓰지 않는다.

이 문서의 수정과 프롬프트 추출은 실제 Flow UI 조작·유료 생성·모션 편집 소프트웨어 구현·최종 영상 검수 완료를 뜻하지 않는다. 기존 작품·정상 자산은 새 기본값으로 자동 덮어쓰지 않는다.
