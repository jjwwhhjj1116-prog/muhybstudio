# 단계 13. 최종 감사·릴리스

## 전수 연결표

`대본 문장 ID | 대본 원문 | 대사 여부 | 시각화 장면 | 주요 인물명 | 보조 인물 앵커 | Flow 인덱스 | 영상 인덱스 | 연속성 상태 | 오류`

## 수량

- 시각화 장면 번호 1부터 연속
- Flow 수 = 시각화 장면 수
- 영상 프롬프트 수 = 시각화 장면 수
- Flow 빈 줄 = N-1
- 영상 빈 줄 = N-1
- CTA·END는 시각화에만 지정 위치 1개씩, Flow·영상 0개

## 내용

- 대본 문장·대사 누락·중복·역순 0
- 주요 인물명과 레퍼런스 불일치 0
- 보조 인물 앵커 누락 0
- 부상·무기·소품·인지·관계·능력 대가 오류 0
- 범용 오류 문구 0
- 제목·썸네일 약속의 대본 근거 100%
- 설명란 12섹션, 타임라인 5~8개, 해시태그 12개, 고정 서명 1개

## 오류 수정

오류가 처음 발생한 최근 승인 지점에서 최소 범위를 고치고, 무효화된 파생물만 재생성한다. 오류 0일 때만 TTS 대본, 시각화, Flow, 영상, 메타데이터, 감사 보고서를 ZIP으로 내보낸다.
