## 상세 캐릭터 시트 — 원본 규격 복구

텍스트만 작성하거나 얼굴 초상만 생성한 상태를 캐릭터 시트 완료로 보고하지 않는다. 주요 인물마다 실제 상세 시트와 생성 등록용 이미지를 별도 제작한다.

- 최상단에 정확한 한글 고정명을 크고 명확하게 표기한다. 영문명은 보조다.
- 한 인물의 전신 정면·측면·후면, 표정 6종, 동작 5종, 의상·장신구·무기·핵심 소품 확대와 색상 팔레트를 구성한다.
- 중성 회색 또는 종이 질감 배경을 사용한다. 자료판에는 여러 칸을 사용할 수 있다.
- 사용자가 확정한 생성 설정은 모델 `gpt-image-2`, 품질 `medium`이다. 사용자 지정 모델·품질을 실제 생성 요청에 적용하고 기록한다. 설정할 수 없는 도구에서 지정했다고 보고하거나 다른 모델로 조용히 대체하지 않는다. 2026-09-07 사용자 직접 확인으로 GPT Image 2를 확정했다.
- 화풍: Korean dark-fantasy martial-arts action manhwa webtoon style, hand-drawn illustration, ink line art with digital coloring. 수작업 잉크 선화, 셀 셰이딩, 수묵 질감, 강한 명암 대비, 영화적 광원과 정교한 재질 표현을 유지한다. 일반 웹툰·부드러운 조명으로 임의 축약하지 않는다.
- 사용자가 제공한 실제 시트를 화풍·밀도·구성의 비교 기준으로 삼는다. 새 작품 인물에게 참고 작품의 얼굴·복장·부상을 무단 복사하지 않는다. 인물별 나이·골격·체격·눈매·위세가 드러나는지 실제 결과를 검수한다.

## 등록용 이미지

사용자 요청대로 실제 캐릭터시트 이미지를 대상 Flow 프로젝트에 업로드하고 캐릭터 이름을 입력해 저장한다. 시트 최상단 한글 이름, 캐릭터 정본의 고정명, 시각화 프롬프트에 쓰인 이름, Flow 등록명은 정확히 일치해야 한다. 별칭·영문명·파일명만으로 등록을 대신하지 않는다.

상세 시트의 프로젝트 등록과 개별 장면에 첨부할 참조 선택은 구별한다. 상세 시트를 프로젝트에 보관·등록하며, 장면의 얼굴·자세·상태 제어가 필요하면 같은 디자인의 무문자 단일 인물 참조를 연결한다. 이 파생 참조를 만들었다고 사용자가 요청한 시트 업로드를 생략하지 않는다. 실제 UI가 시트 입력을 받지 않는 경우 이유와 가능한 입력을 확인하고 미완료 상태를 기록한다.

## Flow 등록까지의 완료 기준

1. 해당 회차의 Flow 프로젝트를 실제 화면과 프로젝트 식별자로 확인한다. 과거 회차 프로젝트를 임의로 대상 삼지 않는다.
2. 기존 등록 인물과 디자인을 확인해 동일 자산의 중복 업로드를 피한다. 다른 디자인을 조용히 덮어쓰지 않는다.
3. 이미지를 업로드하고 고정 한글 이름을 입력하여 저장한다. 기존 이미지 재사용과 이 업로드는 승인된 캐릭터시트 단계에 포함한다.
4. 저장된 캐릭터 목록에서 이름과 썸네일을 다시 확인한다. 비공개 기록에 character_id, canonical_name, Flow 등록명, 프로젝트, 원본 경로·해시, 확인 가능한 자산 ID 및 화면 근거를 남긴다. UI에 없는 ID는 만들지 않는다.
5. 상태는 IMAGE_READY → UPLOADED → NAMED → REGISTRATION_VERIFIED로 구분한다. 실제 장면 입력 첨부는 별도로 확인한다. 텍스트에 이름만 적거나 로컬 파일만 저장한 상태를 등록 완료로 보고하지 않는다.

이름이 변경되면 시각화·Flow 파생 프롬프트·등록 대응표도 함께 대조한다. 로그인·연결·대상 프로젝트가 불명확하면 준비된 이미지는 보존하고 등록만 미완료로 남긴다. 작품 이미지·실제 인물명·프로젝트 주소는 공개 Git에 넣지 않는다.

## 검수

이름 정확성, 구성, 인물 동일성, 설정 연속성, 화풍·외형 매력, 워터마크·로고·UI 흔적을 실제 이미지에서 확인한다. 워터마크가 있는 결과를 무문자 등록 이미지로 통과시키지 않는다. 실패 후보는 후속 참조에서 제외하고 사유를 기록한다. 대본 확정과 이미 허용된 제작은 단계마다 재승인을 요구하지 않고 이어간다.
