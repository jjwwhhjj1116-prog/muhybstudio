# 단계 06. 주요 인물 이미지 생성

## 생성 의무

텍스트 시트를 작성한 주요 인물은 같은 단계에서 전원 실제 이미지를 생성한다. 텍스트만 있으면 미완료다.

## 산출물 분리

주요 인물마다 다음 두 종류를 별도 생성한다.

1. `characters/main/sheets/`: 이름과 여러 자세가 있는 설정 확인용 상세 시트
2. `characters/main/flow_refs/`: Flow 등록용 무문자 단일 인물 이미지

상세 시트를 Flow에 등록하거나 장면 생성에 첨부하면 즉시 실패다.

## 설정 확인용 상세 시트 규격

- 인물마다 별도 한 장
- 최상단에 정확한 **한글 고정명**을 크고 명확하게 표기
- 영문명은 보조 표기
- 이미지 품질 `Medium`
- 서로 다른 인물을 한 이미지에 합치지 않음
- 중성 회색 또는 종이 질감 제작 배경

## 설정 자료판 구성

전신 정면·측면·후면, 표정 6종, 동작 5종, 얼굴·머리·의상·장신구·손목·갑주·문양 확대, 무기·핵심 소품 확대, 색상 팔레트, 짧은 메모.

## 화풍

한국 다크판타지 무협 액션 만화, 수작업 잉크 선화, 디지털 채색, 셀 셰이딩, 은은한 수묵 질감, 강한 명암 대비, 영화적 광원.

금지: 실사, 사진, 3D 렌더, 치비, 아동풍, 밝은 파스텔, 현대 물품, 일본식 문자, 읽을 수 없는 가짜 이름.

## 장면 레퍼런스

합본 설정 자료판은 확인용이다. 시각화 장면에는 `flow_refs`의 단일 전신 이미지만 사용한다.

## Flow 등록용 이미지 규격

- 한 장에 인물 한 명, 전신 한 자세, 중립 배경
- 이미지 내부 글자·이름·숫자·메모·로고·워터마크·UI 0
- 여러 자세·표정판·격자·칸·비교판·회전도·캐릭터시트 구도 0
- 캐릭터 외형이 크게 바뀌는 모든 상태를 별도 이미지로 생성
- 상태별 등록명을 `flow_character_registry.json`에 저장하고 Flow에도 정확히 같은 이름으로 등록
- 예: `주요인물_상태01`, `주요인물_상태02`; 프롬프트에도 같은 등록명만 사용

## 게이트

주요 인물별 텍스트·상세 시트·Flow 등록 이미지 모두 존재, 등록명과 파일의 상태 일치, 상세 시트와 등록 이미지 경로 분리, Medium 품질, 보조 인물 이미지 0, 대본 연속성 모순 0.
