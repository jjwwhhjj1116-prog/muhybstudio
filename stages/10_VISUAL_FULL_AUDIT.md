# 단계 09. 시각화 통합·전수 감사

## 통합

21청크를 장면 번호 순으로 병합한다. 청크 머리말은 제거하고 CTA·END 위치는 유지한다.

## 필수 감사

- 장면 번호 1부터 연속
- 모든 대본 문장 ID 정확히 한 번 매핑
- 모든 직접 대사 원문 보존
- 원문 순서 보존
- CTA·END 각각 1개, 장면 수 제외
- 주요 인물은 현재 상태별 Flow 등록명과 완전 일치
- 기본 이름·이전 상태 등록명·미등록 상태명 0
- 주요 인물 외모 장문 반복 0
- 보조 인물 이름·역할명 단독 사용 0
- 화풍 머리말 누락 0
- 부상·무기·소품·시간·장소 연속성 오류 0
- 빈 영어 프롬프트와 범용 오류 문구 0
- 캐릭터시트·격자·여러 칸·비교판 유도어 0
- 읽을 수 있는 이름·제목·자막·로고·워터마크·UI 허용 표현 0
- 모든 Flow 프롬프트가 같은 번호의 시각화 영어 프롬프트와 바이트 정규화 기준 완전 일치

## 감사 테이블

`문장 ID | 대본 원문 | 대사 여부 | 장면 번호 | 주요 인물 | 보조 앵커 | 연속성 | 오류`

대사 하나라도 누락되면 Flow 단계 진입을 차단한다.
