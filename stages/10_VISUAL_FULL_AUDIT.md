## 텍스트·계획 검수

1. 제작 버전과 해당 승인 대본·해시·장면표를 연결한다. 두 버전의 공통 세계관·인물·주요 인과·결말과 버전별 승인 원고·파생물을 구별한다. 같은 번호만으로 원고·자산·제목을 혼용하지 않는다.
2. 다음 신작의 공개 한 화는 내부 네 부 전체 N≤200·1~N이다. 원문 위치·나레이션·발화·감정 태그·큰따옴표·순서의 누락·중복을 검사한다. 약 2~3문장 묶음이 초과해 통합했다면 같은 장소·시간·행동의 의미가 유지되는지 읽는다. 미해결 충돌이 있으면 완성본으로 처리하지 않는다.
3. `NOVEL`은 시각화 N=이미지 N=Flow 영상 N, `WEBTOON_EXPERIMENT`는 시각화 N=기본 이미지 N=모션 편집 계획 N이다. 웹툰 선택 Flow K개(K≤N)가 원래 장면 ID·번호를 유지하는 부분 목록인지 확인한다. 빈 영상·1~K 재번호·숨은 A/B/C 생성으로 수량을 꾸미지 않는다.
4. 각 이미지의 단일 순간·표정·시선·손 역할·무기·소품·부상·젖음·구속·소유권을 해당 원문과 대조한다. 공통 상태 문구가 사건 전·후의 행동을 미리 적용하거나 되돌리지 않는지 읽는다. 비노골적인 화면 해석도 원문 인과·실제 나이를 보존하는지 확인한다.
5. 생성 길이와 최종 표시 시간·모션 편집 계획을 구별한다. 8초×200개=26분 40초를 약 80분 전체의 생성 움직임으로 보고하지 않는다. 평균 24초·약 20~30초 참고값을 강제하지 않으며 실제 TTS 미입력은 예상이다. 자동 연장·3배 감속·무한 반복으로 계획을 채우지 않는다.
6. 웹툰 반응 컷의 참조·크롭 재사용과 실제 새 그림을 해시·원문 대응·수량으로 구별한다. 새 사건 누락이나 좌우 반전으로 부상·손 역할이 바뀌지 않는지 확인한다. 기본 생성 이미지의 테두리 금지와 후편집 판넬 경계 선택을 구별한다.

## 실제 자산·영상 검수

문서·해시 검사와 실제 생성·음성·편집 검수는 별개다. 실제 시작 입력·종료 입력을 사용하는 경우 두 프레임과 완성 클립의 중간 동작·얼굴·몸·무기·속도·방향을 직접 대조한다. 입력에 이미 완료된 행동을 다시 실행하도록 지시하지 않았는지 확인한다. 실제 이미지·TTS가 없으면 영상과 표시 시간은 DRAFT로 유지한다.

웹툰은 실제 편집 화면의 한국어 글자·말풍선 화자·읽는 순서·가독성·얼굴 가림·동일 대사의 자막 중복, 성우 음성과 반응 컷의 시점을 검사한다. NOVEL은 소설형 나레이션과 선택 화면의 타이밍을 검사한다. 전체 재생·실측 시간 확인 전 최종 영상 완료로 승격하지 않는다. 기존 승인 작품은 자동으로 새 분할 계약에 이관하지 않는다.
