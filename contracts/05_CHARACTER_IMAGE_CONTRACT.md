# 캐릭터 이미지 계약

주요 인물 이미지는 용도가 다른 두 종류를 반드시 분리한다. 두 종류를 같은 파일로 대신할 수 없다.

## A. 설정 확인용 상세 시트

- 대상: 주요 인물만.
- 이름: 이미지 최상단에 정확한 한글 고정명.
- 구성: 전신 3면, 표정 6종, 동작 5종, 의상·무기·소품 디테일, 팔레트, 메모.
- 용도: 제작진의 설정 확인만. Flow 캐릭터 등록, 장면 레퍼런스, 시각화 생성에 첨부 금지.

## B. Flow 캐릭터 등록용 단일 레퍼런스

- 한 파일에 한 사람, 전신 한 자세, 중립적인 단색·수묵 배경만 둔다.
- 이미지 안에 이름·한글·영문·숫자·메모·로고·워터마크·UI를 넣지 않는다.
- 여러 표정·여러 자세·여러 칸·전후 비교·회전도·시트·프레임·테두리를 넣지 않는다.
- 소품은 정체성에 꼭 필요한 대표 소품 하나만 허용한다.
- Flow 등록명은 `flow_character_registry.json`의 `registered_name`과 완전히 일치시킨다.
- 신체 연령·부상·가면·변장처럼 외형이 크게 변하는 상태는 이미지와 등록명을 상태별로 분리한다. 예: `주요인물_상태01`, `주요인물_상태02`.
- 시각화 프롬프트는 전체 외모를 되풀이하지 않고 정확한 `registered_name`, 현재 소지품, 행동만 쓴다.

## 공통

- 품질: Medium.
- 화풍: 한국 다크판타지 무협 액션 만화, 잉크 선화, 디지털 채색, 셀 셰이딩, 수묵 질감, 강한 명암, 영화적 광원.
- 보조 인물: 이미지 0, 시트 0, 영어 외형 앵커만.
- 게이트: 상세 시트와 Flow 등록 이미지의 파일 경로가 같으면 실패. Flow 등록 이미지에 읽을 수 있는 글자나 시트형 구성이 있으면 실패.
