문장 소유권 유지, 의미 장면과 샷·시간 매핑 분리. 구문서를 새 지침과 함께 적용하지 않는다. 이전 내용은 Git 이력에 보존되어 있다.

다음 신작은 내부 16부·각 약 20분을 네 부씩 공개 4화·각 약 80분에 배정한다. 분할은 버전별 공개 한 화 전체에 1~N으로 이어지고 **N≤200**이다. 약 2~3문장의 의미 묶음에서 출발하되 한 문장마다 자동 분할하지 않는다. 전체 원문 위치·화자·감정 태그·큰따옴표를 중복 없이 소유하고, 다른 시간·장소·상태를 한 이미지에 겹치지 않는다.

동일 이야기의 `NOVEL`(기존 무협소설, 기본값)과 `WEBTOON_EXPERIMENT`(신규 무협웹툰 실험)은 세계관·인물·주요 인과·결말을 공유한다. 승인 대본·해시·장면표와 파생물은 버전별로 분리하며 같은 번호만으로 입력을 혼용하지 않는다. 기존 작품은 자동 재배분하지 않는다.

- NOVEL: 시각화 각 번호에 이미지 하나·Flow 영상 하나, N=N=N≤200으로 대응한다.
- WEBTOON_EXPERIMENT: 시각화 각 번호에 기본 이미지 하나·모션 편집 계획 하나, N=N=N≤200으로 대응한다. 선택 Flow K개(K≤N)는 원래 장면 ID·번호를 유지하는 부분 목록이다. 1~K로 재번호하거나 빈 영상 항목을 만들어 전체 N개로 표시하지 않는다.

초기 묶음이 200을 넘으면 같은 장소·시간·행동의 인접 묶음을 의미가 유지되는 범위로 통합하고 이유를 남긴다. 원문 삭제·요약·거대한 문장 재작성으로 맞추지 않는다. 원문 전체와 의미를 보존한 통합이 불가능하면 충돌과 사용자 조정 필요를 기록하고 임의 초과 납품하지 않는다. 재분할 시 해당 버전의 기본 이미지·모션 또는 영상·선택 목록을 함께 개정한다. 내부 샷·키프레임·후속 후보로 상한과 원문 대응을 해제하지 않는다.

생성 길이와 최종 표시 시간은 별개다. 4,800초/200장면의 평균 24초·약 20~30초 구간은 계획 참고다. 8초×200은 1,600초·26분 40초이며 약 80분 전체의 연속 생성 움직임을 뜻하지 않는다. 같은 번호 안의 이미지 유지·크롭·움직임 또는 웹툰 오버레이 편집 계획을 별도 기록한다. 자동 Extend·3배 감속·무한 반복으로 채우지 않는다. 실제 TTS·선택 프레임이 없으면 시간·영상 지시는 초안이며 실제 완성 시간은 별도 실측한다.

웹툰의 반응 컷과 말풍선은 원래 장면의 원문에 연결한다. 승인 표정·크롭 재사용과 실제 새 그림 생성은 파일·해시·수량으로 구별하며 새 사건을 장면 안에 숨기지 않는다. 상세한 편집·음성·말풍선 지시는 낭독 본문 밖에 둔다.
