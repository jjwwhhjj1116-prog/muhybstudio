# 08. 무승인 연속 실행

## 적용 조건

프로젝트 매니페스트의 `execution.auto_continue_chunks`가 `true`이고 사용자가 청크별 승인을 요구하지 않았을 때 적용한다.

## 실행 루프

1. 현재 청크 입력과 직전 상태를 읽는다.
2. 청크 하나만 생성한다.
3. 문서에 해당 청크만 별도 쓰기 요청으로 추가한다.
4. 읽어 되돌려 받아 말미와 장면 번호를 검증한다.
5. 상태 파일과 해시를 갱신한다.
6. 차단 오류가 없으면 다음 청크로 이동한다.

## 대기 정책

- 출력 제한 회피는 실제 1~2분 수면이 아니라 **작은 청크, 별도 쓰기 요청, 읽기 검증, 체크포인트**로 해결한다.
- 커넥터가 429·일시 오류를 반환하면 30초, 60초, 120초 순으로 재시도할 수 있다.
- 같은 오류가 3회 반복되면 `FAILED`로 멈추고 재개 지점을 보존한다.
- 사용자에게 매 청크 승인을 묻지 않는다. 차단 오류, 권한 문제, 정본 충돌만 보고한다.

## 컨텍스트 절약

다음 청크에는 전체 대화를 다시 넣지 않는다. 정본, 청크 지도, 직전 상태, 직전 본문 마지막 두 행동, 이번 목표만 로드한다. 중간 감사 청크에서는 누적 상태표와 열린 복선을 추가한다.
