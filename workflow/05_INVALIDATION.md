# 05. 변경 영향과 무효화

| 변경 | 반드시 무효화할 후속 산출물 |
|---|---|
| 시놉시스·설정집 | 대본 이후 전부 |
| 대본 사건·대사·인물 상태 | 영향 캐릭터시트, 시각화, Flow 전체, 영상, 메타데이터 |
| 주요 인물 캐릭터시트·이미지 | 해당 인물 등장 시각화, Flow 전체, 해당 영상, 썸네일 |
| 보조 인물 앵커 | 해당 보조 인물 등장 시각화, Flow 전체, 해당 영상 |
| 시각화 문구·장면 순서·장면 수 | Flow 전체, 영향 영상, 최종 감사 |
| Flow | Flow 감사, 영상 수량 감사 |
| 영상 프롬프트 | 해당 영상과 최종 감사 |
| 제목·설명란·썸네일 | 메타데이터 감사 |
| 범용 지침 | 영향받는 모든 단계 |

## 기록 필드

변경 파일, 변경 전후 해시, 변경자, 시각, 변경 요약, 영향 청크·장면·인물, 무효화 단계, 재생성 범위, 재승인 상태를 기록한다.

## 금지

- 시각화 변경 뒤 Flow 일부 줄만 손수 수정
- 중간 장면 삭제 뒤 번호 방치
- 대본 대사 변경 뒤 옛 `[한국어 번역]` 유지
- 캐릭터 이미지 변경 뒤 옛 레퍼런스 ID 유지
- 오류 하나 때문에 영향 없는 전체 산출물을 임의 재작성
