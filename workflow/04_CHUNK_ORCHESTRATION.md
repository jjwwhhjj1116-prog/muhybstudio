# 04. 21청크 오케스트레이션

## 공통 원칙

- 청크는 전송 단위이며 서사 단위가 아니다.
- 청크 경계에서 장소·사건·감정을 억지로 닫지 않는다.
- 장면과 대화의 한가운데서 자르지 않는다.
- 새 Hook, Intro, CTA, 요약, 인물 재소개, 가짜 클리프행어, End를 추가하지 않는다.

## 대본 청크

- 기본 총 21개, 공백 포함 총 63,000~68,000자.
- 균등 기준은 청크당 약 3,000~3,250자지만 이야기 장면 경계를 우선한다.
- 청크 지도는 `시작 상태 → 반드시 진행할 사건 → 선택 → 대가 → 목표 종료 상태`를 가진다.
- 5·10·15·20청크 뒤 누적 감사를 실시한다.

## 시각화 청크

- 기본 총 21개. 대본 청크와 같은 번호를 권장하되 장면 경계상 범위가 다르면 원문 문장 ID로 연결한다.
- 청크당 최대 25장면을 기본 상한으로 한다. 장면 폭증 시 대본 2~3문장 묶기 규칙을 재검토한다.
- 장면 번호는 청크마다 1로 초기화하지 않고 전편에 걸쳐 연속한다.

## 청크 종료 체크포인트

- 마지막 원문 문장 ID와 텍스트
- 마지막 두 행동
- 마지막 장면 번호와 누적 장면 수
- 다음 시작 문장 ID
- CTA·END 사용 상태
- 인물별 생존·나이·부상·피로·무기·소지품·인지·관계·능력 대가
- 장소·시간·세계 상태
- 열린 복선과 회수된 복선
- 출력 파일 해시와 검수 결과

## 재시도

출력이 끊기면 해당 청크 전체를 덧붙이지 않는다. 마지막으로 완결된 문장 또는 장면을 찾아 불완전 꼬리를 제거하고 동일 청크 번호로 다시 생성한다. 중복 여부를 검사한 뒤에만 다음 청크로 넘어간다.
