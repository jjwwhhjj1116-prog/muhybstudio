# 00. 부팅 순서

## 목적

새 채팅, 컨텍스트 압축, 모델 교체, 작업자 교체 뒤에도 같은 기준과 마지막 상태에서 재개한다.

## 필수 읽기 순서

1. 루트 `AGENTS.md`
2. `VERSION.json`
3. `workflow/01_AUTHORITY_AND_CANON.md`
4. `workflow/02_PROJECT_LIFECYCLE.md`
5. 대상 작품 `project_manifest.json`
6. 대상 작품 `PROJECT_CONTEXT.md`
7. `stage_status.json`
8. 현재 단계의 `stages/*.md`
9. 현재 단계가 참조하는 직전 승인 산출물
10. 현재 청크가 있으면 직전 청크 본문 마지막 두 행동과 직전 상태 파일 전체

## 부팅 결과

작업을 시작하기 전에 내부적으로 다음을 확정한다.

- 프로젝트 ID와 작품명
- 한 편짜리 장편 여부
- 현재 단계와 상태
- 정본 버전·해시
- 마지막 승인 청크와 다음 청크
- 마지막 장면 번호와 다음 장면 번호
- CTA·END 사용 여부
- 인물별 현재 나이·부상·무기·소지품·인지·관계·능력 대가
- 사용자가 자동 연속 진행을 허용했는지

## 중단 조건

- 정본 파일이 없거나 읽히지 않음
- 대상 작품을 특정할 수 없음
- 승인 산출물과 상태 파일의 해시가 다름
- 두 권한 출처가 충돌하고 최신 확정 지시로 해소되지 않음
- 직전 청크 종료 지점과 다음 청크 시작 지점이 맞지 않음

중단 시 임의 보정하지 말고 `reports/boot_blocker.md`에 출처, 충돌, 필요한 결정을 기록한다.
