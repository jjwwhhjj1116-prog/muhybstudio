# 시작과 복구

1. AGENTS.md, VERSION.json, workflow/12_THREE_PC_SYNC.md를 읽는다.
2. git status, remote, 현재 브랜치를 확인하고 fetch한다. 다른 PC의 변경과 미커밋 작업을 확인한 뒤에만 갱신한다.
3. coordination/STATUS.md에서 공통 워크플로우의 마지막 완료/다음 작업과 미구현 기능을 읽는다.
4. 현재 단계의 stages 문서와 연결된 policy 문서를 읽는다. 집필은 policy/01_WRITING.md를 거쳐 복원된 최초 V12 FULL 전문과 출력 계약을 읽는다.
5. 작품 작업이면 별도 비공개 프로젝트를 연결하고 project_manifest.json의 workflow 버전과 Git SHA, PROJECT_CONTEXT.md, stage_status.json, memory/checkpoint.json 및 관련 근거 원문을 읽는다.
6. 작품의 마지막 장면, 현재 상태·인지·감정·복선과 다음 작업을 확인한다. 대화가 이어지면 마지막 두 문장만 읽지 않는다.

공통 지침·코드 관리에는 비공개 작품이 없어도 된다. 작품 정본이 누락/충돌하면 의존 작업만 대기하고 복구 가능한 독립 작업을 진행한다. 오래된 프로젝트를 조용히 덮어쓰지 않고 버전 전환의 영향과 검증 결과를 남긴다.
