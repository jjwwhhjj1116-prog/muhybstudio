# 02. 프로젝트 생명주기

## 단계 순서

| 번호 | 단계 | 진입 조건 | 주요 출력 |
|---|---|---|---|
| 00 | 초기화 | 작품 아이디어 | 매니페스트, 폴더, 정본 목록 |
| 01 | 시놉시스·설정집 | 초기화 완료 | 로그라인, 인물, 세계 규칙, 완결, 21청크 지도 |
| 02 | 대본 | 설정집 APPROVED | 대본 21청크, 청크 상태 |
| 03 | 대본 감사 | 21청크 완료 | 통합 대본, 전수 감사 |
| 04 | 인물 분류 | 대본 APPROVED | 주요 인물 목록, 보조 인물 앵커 목록 |
| 05 | 캐릭터시트 | 인물 분류 잠금 | 주요 인물 텍스트 시트 |
| 06 | 인물 이미지 | 캐릭터시트 APPROVED | 이름 표기 캐릭터시트 이미지, 장면 레퍼런스 |
| 07 | 시각화 전처리 | 대본·이미지 APPROVED | 문장 ID, 장면 분할 지도 |
| 08 | 시각화 | 전처리 완료 | 21청크 시각화 프롬프트 |
| 09 | 시각화 감사 | 시각화 완료 | 통합본, 100% 문장 매핑 감사 |
| 10 | Flow | 시각화 APPROVED | Python 생성 Flow |
| 11 | 영상 프롬프트 | Flow APPROVED | 장면별 무음 움직임 지시 |
| 12 | 메타데이터 | 최종 영상 순서 잠금 | 제목 3안, 썸네일 3안, 설명란, 타임라인 |
| 13 | 릴리스 감사 | 전 단계 완료 | 감사 보고서와 배포 ZIP |

## 상태

`NOT_STARTED`, `IN_PROGRESS`, `NEEDS_REVIEW`, `APPROVED`, `INVALIDATED`, `FAILED`

직전 단계가 `APPROVED`가 아니면 다음 단계는 시작할 수 없다. 프로젝트 설정에서 사용자 무승인 연속 진행이 활성화되면 **청크 승인만 자동화**하고 단계 게이트 검수는 생략하지 않는다.
