# 10. 오류 처리와 최소 복구

## 차단 오류

- 정본 또는 대상 문서 접근 실패
- 대본 문장·직접 대사 누락
- 장면 번호 중복·공백·역순
- 주요 인물 이름 불일치
- 보조 인물 앵커 누락
- CTA·END 중복 또는 오위치
- Flow·영상 수량 불일치
- 범용 오류 문구가 산출물에 포함
- Google Docs 쓰기 결과 미확인
- Git 원격·공개 범위 불확실
- Google Docs 문서 전체 용량 한계

## 복구 원칙

1. 마지막 승인 해시를 찾는다.
2. 오류가 처음 생긴 최소 범위를 찾는다.
3. 불완전 범위만 재생성한다.
4. 무효화 규칙에 따라 후속 자동 산출물을 재생성한다.
5. 읽기 검증 후 상태를 되돌린다.

`죄송합니다`, `계속할까요`, `다음 청크를 제공하겠습니다`, 정책 거절문 등 작업 외 문구가 산출물 안에 들어가면 해당 청크는 실패다.

Docs가 `FAILED_PRECONDITION`을 반환하면 먼저 마지막 정상 장면과 다음 장면 부재를 확인한다. 축소 요청과 한 장면 요청까지 실패하면 동일 파일 재시도를 멈추고 `workflow/11_DOCUMENT_CAPACITY.md`로 전환한다.
