# 06. 새 채팅·컨텍스트 복구

## 복구 묶음

새 채팅에는 대화 요약 대신 다음 파일을 기준으로 한다.

1. `VERSION.json`
2. 프로젝트 매니페스트
3. 작품 컨텍스트
4. 단계 상태
5. 승인된 누적 산출물 또는 현재 단계에 필요한 최소 승인본
6. 직전 청크 상태 파일
7. 현재 청크 목표
8. 열린 오류와 무효화 기록

## 복구 절차

1. 파일 존재·해시·버전을 검증한다.
2. 마지막 완료 청크와 다음 청크를 비교한다.
3. 직전 본문의 마지막 두 행동과 상태 장부를 대조한다.
4. 현재 단계 지침을 다시 읽는다.
5. 대본이면 다음 문장, 시각화면 다음 원문 문장 ID와 다음 장면 번호를 확정한다.
6. 이미 완료된 범위를 재생성하지 않는다.

## 복구 실패

필수 파일이 없으면 새 내용을 창작하지 않는다. `reports/recovery_blocker.md`에 누락 파일, 마지막 신뢰 지점, 복구 가능한 범위를 기록한다.
